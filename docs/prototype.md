# 家づくりプロトタイプ（v0.1）

[技術構成](./tech-stack.md) の「4. 最小プロトタイプの範囲」を実装したものです。お金の仕組みはまだ入っていません。

## できること

| 項目 | 内容 |
|---|---|
| 土地 | 24 × 20 マス（1マス = 910mm）。前面道路つき |
| 床 | ドラッグで四角く張る。フローリング・畳・タイル・カーペット |
| 壁 | マス目の線に沿ってドラッグ。床のない側が自動で外壁、床のある側が内装になる |
| 外壁材 | 窯業系サイディング、外壁タイル、塗り壁、木の羽目板、ガルバリウム角波（各6色＋自由な色） |
| ドア | 玄関ドア（片開き・親子）、室内ドア、引き戸。扉の色・枠の色を選べる |
| 窓 | 引き違い窓（大・小）、掃き出し窓、縦すべり出し窓、FIX窓、高窓。サッシの色を選べる |
| 開口 | 壁に実際に穴が開き、半マス（455mm）単位で位置を決める。重なりや壁からのはみ出しは置けない |
| 階段 | 直階段（幅1マス × 長さ4マス、14段）。2階の床には自動で吹き抜けの穴が開く |
| 屋根 | 切妻・寄棟・片流れ・陸屋根。勾配（1〜8寸）、軒の出、棟の向き、屋根材（瓦・スレート・立平・防水シート）と色 |
| 妻壁 | 屋根の下の三角の壁（陸屋根はパラペット）の外壁材も別に選べる |
| 家具 | ベッド、ソファ、ダイニング、チェア、テレビボード、デスク、本棚、キッチン、冷蔵庫、観葉植物、ラグ。自由な位置・向き |
| 編集 | 選んだパーツの種類・素材・色を右のパネルで変更。削除、取り消し / やり直し |
| 表示 | 階ごとの表示切り替え、太陽光と影、素材の模様と凹凸、ガラスの映り込み |
| セーブ | 自動セーブ（再読み込みしても家が残る）＋ 3つのセーブスロット |
| 歩きモード | キャラクターを WASD で動かし、一人称・三人称で家の中を見て回れる（下に詳細） |

![サンプルの家](images/prototype-sample.png)

最初はサンプルの2階建て（切妻屋根）が建っています。「セーブ / ロード」→「更地にする」で一から建てられます。

## 操作

| 操作 | マウス・キー |
|---|---|
| ツールの持ち替え | 上のボタン、または V（選択）F（床）W（壁）D（ドア）N（窓）S（階段）T（屋根）G（家具）E（削除） |
| 作業する階 | 下のボタン、または 1 / 2 キー |
| 視点の回転 | 選択・削除ツール：左ドラッグ ／ 建てるツール：右ドラッグ |
| 視点の移動 | 選択・削除ツール：右ドラッグ ／ 建てるツール：中ドラッグか Shift＋右ドラッグ |
| ズーム | ホイール |
| 向きを変える | R（階段・家具） |
| 家具を動かす | 選んでからドラッグ、または矢印キーで5cmずつ |
| 削除 | Delete キー、または削除ツールでクリック |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Y（Mac は ⌘） |

## 歩きモード（プレイヤー）

上の「歩いてみる」ボタンか Tab キーで、建てた家の中を自分のキャラクターで歩けます。もう一度 Tab で建築モードに戻ります。

| キー | 操作 |
|---|---|
| W / S | 前へ / 後ろへ |
| A / D | 左へ / 右へ（横歩き） |
| Shift | 押している間は走る |
| Space | ジャンプ |
| C | しゃがむ / 立つ（切り替え） |
| Q | 一人称 ⇄ 三人称 |
| R | カメラを背中側に戻す |
| F / E | 近くのドアを開ける / 閉める（画面のボタンでも可） |
| マウス | 画面をクリックすると視点操作（Esc で解除）。ドラッグでも回せる |
| ホイール | 三人称のカメラの距離 |
| Tab | 建築モードに戻る |

- 壁は通り抜けられません。ドアは閉まっていると通れず、開けると通れます（窓は通れません）。
- ドアに近づくと足もとに光の輪が出て扉がほんのり光り、画面に「F ドアを開ける」ボタンが出ます。開け閉めすると扉が蝶番で回り（引き戸は横にすべり）、ラッチ・きしみ・閉まる音が鳴ります。扉はプレイヤーから遠ざかる向きに開きます。
- 基礎の高さ（500mm）は段差として上がれます。階段で2階へ上がれ、2階の吹き抜けから落ちると1階に着地します。
- 家具にはぶつかります（ラグは踏めます）。
- 三人称のカメラは壁や屋根に埋もれないよう手前に寄ります。
- 当たり判定の計算は `src/building/walk.ts` にあり、テストがあります。

## 一軒建てる手順

1. 「セーブ / ロード」→「更地にする」を2回押して空き地にする
2. 1階を選び、「床」でドラッグして床を張る
3. 「壁」で床の外周をなぞる
4. 「ドア」「窓」で壁をクリックして付ける
5. 「階段」で1階の床に階段を置く
6. 2階を選び、同じように床と壁を作る（階段の上は自動で穴が開く）
7. 2階のまま「屋根」で範囲をドラッグする
8. 「選択」でパーツを選び、外壁材や屋根の形・色を整える
9. 「家具」で家具を置く

## コードの置き方

```
src/
  building/   パーツの型、寸法、配置ルール、屋根の形の計算、サンプルの家（描画に依存しない）
  catalog/    素材・窓とドア・家具のカタログ（JSON）。種類を増やすときはここにデータを足す
  world/      3D描画（地面、光、壁・床・屋根などの形づくり、配置操作）
  ui/         メニューとパネル（React）
  state/      ゲーム状態と取り消し履歴（Zustand）
  save/       ブラウザ内へのセーブとロード
```

配置の可否（壁の重なり、窓が壁に収まるか、階段の位置など）は `src/building/rules.ts` にまとめ、描画から切り離しています。将来サーバーで同じ判定をするときにそのまま移せます。
