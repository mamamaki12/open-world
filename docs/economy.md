# お金の仕組み（v0.1）

[設計書](./game-design.md) の「3. お金の仕組み」を実装したものです。一人で遊べる範囲（市場への売却）まで入っています。他のプレイヤーとの売買はサーバーが必要なので、次の段階です。

画面の上の真ん中に **所持金・日付・相場** と、**🏠 不動産** と **🎰 カジノ・競技場** の入り口があります。

## 遊びの流れ

1. 建築モードで自由に設計する（設計はタダ。何度でもやり直せる）
2. 上の「🔨 着工 ¥○○」から不動産屋を開き、**着工** すると工事費を払って工事が始まる（15秒〜3分）
3. 工事が終わると家が「建った」ことになり、査定が付く
4. **土地ごと売る**（相場しだいでもうけも損も出る）か、**貸して** 毎日家賃をもらう
5. 稼いだお金で別の土地を買い、もっと良い家を建てる

- はじめは所持金 2,000万円と、郊外の土地（評価 500万円）を1つ持っています。サンプルの家（約1,760万円）はそのまま建てられます。
- 建ったあとで設計を変えると、**変えた部分だけ** 改築費がかかります（足したパーツ、素材・色・種類を変えたパーツ）。取り壊しは無料（返金なし）。家具の位置や向きを変えるだけならお金はかかりません。
- 売れるのは「建っている家」です。設計を変えても、着工するまで売値には反映されません。

## 1日と相場

- ゲーム内の1日 = 実時間の60秒。遊んでいる間だけ進みます。
- 毎日、不動産の **相場**（1.00 が平均、0.5〜2.0）が上下します。平均に戻ろうとする動きに、ときどき好況・不況の大きな動きが混ざります。「不動産 → 相場」でグラフが見られます。
- 毎日、持っている土地と家に **維持費**（建築費の0.05%）と **固定資産税**（土地＋建物の評価の0.03%）がかかり、貸している家からは **家賃**（売値の0.3%）が入ります。

## 値段の決まり方

| 項目 | 計算 |
|---|---|
| 工事費 | パーツごとの単価の合計。床は面積 ×（構造＋床材）、壁は壁面積 ×（骨組み＋外壁材／内装材）、屋根は屋根面積 ×（下地＋屋根材）、ドア・窓・階段・家具は1つずつ |
| 建物の査定 | 工事費 × 品質係数 × 立地 |
| 売値 | （建物の査定 ＋ 土地）× 相場 |
| 土地の値段 | 立地ごとの基準 × ばらつき（0.85〜1.2）× 相場 |

単価は `src/catalog/prices.json`（素材・ドア・窓・家具）と `src/economy/pricing.ts` の `STRUCTURE`（基礎・骨組み・下地・階段）にあります。数字を変えるだけで調整できます。

### 品質係数（0.75 から始まり、工夫すると上がる）

| 条件 | 係数 |
|---|---|
| 玄関ドアがある | +0.05 |
| キッチンがある | +0.10 |
| お風呂がある（家具に「ユニットバス」を追加） | +0.10 |
| トイレがある（家具に「トイレ」を追加） | +0.08 |
| ベッドがある | +0.05 |
| 窓が十分ある（床15m²に1つ以上） | +0.07 |
| 家具・インテリアが充実（ソファ・テレビ・本棚・植物・ラグが4つ以上） | +0.05 |
| 外壁の素材が2種類以内（統一感） | +0.05 |
| 屋根がかかっていない | −0.30 |
| 2階があるのに階段がない | −0.30 |

### 立地（土地を買うときに選ぶ）

| 立地 | 土地の基準 | 建物の査定 |
|---|---|---|
| 郊外の住宅地 | 500万円 | ×0.9 |
| 静かな住宅街 | 1,200万円 | ×1.0 |
| 駅近 | 2,500万円 | ×1.15 |
| 都心の一等地 | 6,000万円 | ×1.3 |

売り土地は毎日入れ替わります。土地は何か所でも持てて、「持っている土地」から行き来できます（土地ごとに設計図が別々に残ります）。最後の土地を売ると、画面の設計図だけが手元に残り、次に買った土地でそのまま建てられます。

## カジノ・競技場

賭け金に上限はありません（所持金まで）。どのゲームも長く続けると少し損をするように作ってあり、バイトの価値を守ります。

| ゲーム | 遊び方 | 還元率 |
|---|---|---|
| スロット | 3本のリール。7・BAR・ベル・スイカ・レモンの3つそろい、左のチェリーで元返し | 93.5% |
| ルーレット | ヨーロピアン（0〜36）。赤／黒、奇数／偶数、前半／後半（×2）、1〜12 などの3分の1（×3）、一点（×36） | 97.3% |
| ハイ＆ロー | 次のカードが大きいか小さいか（同じ数字は負け）。倍率は当たりやすさで決まり、当てたらそのまま続けて倍々に挑める | 95% |
| 競馬 | 10頭立て。単勝・複勝（3着以内）・馬連・ワイド・馬単 | 75〜80% |
| 競輪 | 9車立て。2車複・2車単・ワイド（実際の競輪にならって単勝はなし） | 75% |
| ボートレース | 6艇立て。単勝・複勝（2着以内）・2連複・拡連複・2連単。実際と同じく内側の1号艇が勝ちやすい | 75% |

- 公営競技は、出走表を作るたびに同じレース模型を6,000回走らせて確率を出し、そこからオッズを決めます（払戻率は実際の公営競技に近い値）。結果も同じ模型で走らせるので、オッズどおりの当たりやすさになります。
- 出走表の「予想」の印（◎○▲△✕）は実力の順位です。レースは区間ごとに調子がぶれるので、人気どおりにならないこともあります。
- 1レースで何枚でも買えます。レースの途中でメニューを閉じても払い戻しは受け取れます。走る前に閉じた券は返金されます。

## バイト（仮）

ミニゲームのバイトは次の段階で作ります。それまでのつなぎとして、「不動産 → 家計簿・バイト」に **チラシ配り**（10秒で1万2千円）があります。お金が尽きたときの立て直し用です。

## セーブ

お金・土地・建った家・相場・家計簿はブラウザ内（localStorage の `open-world:economy:v1`）に自動で保存されます。「家計簿・バイト」の一番下で、お金と土地を最初からやり直せます。セーブスロット（設計図の保存）はこれまでどおり使えます。読み込むのは設計図だけなので、お金は変わりません。

## まだ入っていないもの

- 他のプレイヤーとの家の売買（サーバーと不正対策が必要）
- ミニゲームのバイト
- 建てる前（未着工）の部分を3Dで半透明に見せる表示
- 築年数による値下がり、土地の広さの違い、ワールド上に複数の土地を並べる表示
- 数値のバランス調整（遊んでみてから）
