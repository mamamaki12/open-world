# お金の仕組み（v0.1）

[設計書](./game-design.md) の「3. お金の仕組み」を実装したものです。一人で遊べる範囲（市場への売却）まで入っています。他のプレイヤーとの売買はサーバーが必要なので、次の段階です。

画面の上の真ん中に **所持金・日付・相場** と、**🏠 不動産** の入り口、**🎰 カジノへ行く** ボタンがあります。

## 遊びの流れ

1. 建築モードで自由に設計する（設計はタダ。何度でもやり直せる）
2. 上の「🔨 着工 ¥○○」から不動産屋を開き、**着工** すると無料で工事が始まる（15秒〜3分）。建てた家は売るときに査定どおりのお金になる
3. 工事が終わると家が「建った」ことになり、査定が付く
4. **土地ごと売る**（相場しだいでもうけも損も出る）か、**貸して** 毎日家賃をもらう
5. 稼いだお金で別の土地を買い、もっと良い家を建てる

- はじめは所持金 100万円と、郊外の土地（評価 500万円）を1つ持っています。着工は無料なので、サンプルの家もそのまま建てられます。
- 建ったあとで設計を変えると、**変えた部分だけ** 改築費がかかります（足したパーツ、素材・色・種類を変えたパーツ）。取り壊しは無料（返金なし）。家具の位置や向きを変えるだけならお金はかかりません。
- 売れるのは「建っている家」です。設計を変えても、着工するまで売値には反映されません。

## 1日と相場

- ゲーム内の1日 = 実時間の60秒。遊んでいる間だけ進みます。
- 毎日、不動産の **相場**（1.00 が平均、0.5〜2.0）が上下します。平均に戻ろうとする動きに、ときどき好況・不況の大きな動きが混ざります。「不動産 → 相場」でグラフが見られます。
- 毎日、持っている土地と家に **維持費**（建築費の0.05%）と **固定資産税**（土地＋建物の評価の0.03%）がかかり、貸している家からは **家賃**（売値の0.3%）が入ります。

## 値段の決まり方

| 項目 | 計算 |
|---|---|
| 建築費（着工は無料。査定のもと） | パーツごとの単価の合計。床は面積 ×（構造＋床材）、壁は壁面積 ×（骨組み＋外壁材／内装材）、屋根は屋根面積 ×（下地＋屋根材）、窓・ドアは1つずつ（サッシの種類で ×1〜2.2）、階段は1つ ＋ 踏み板 5m² × 木部の素材、家具は1つずつ |
| 建物の査定 | 建築費 × 品質係数 × 立地 |
| 売値 | （建物の査定 ＋ 土地 × にぎわい）× 相場 |
| 土地の値段 | 立地ごとの基準 × ばらつき（0.85〜1.2）× にぎわい（0.8〜1.6）× 相場 |
| にぎわい | 区画から80m以内の建物の重さを近いほど大きく足す（戸建て1、2階建て以上の自分の家1.5、アパート1.5、マンション2.5、タワー3.5、お店4、カジノ6）。係数 = 0.8 + 合計 × 0.033（`src/economy/neighborhood.ts`） |

単価は `src/catalog/prices.json`（素材・ドア・窓・家具）と `src/economy/pricing.ts` の `STRUCTURE`（基礎・骨組み・下地・階段）にあります。数字を変えるだけで調整できます。

|---|---|

| トイレがある（家具に「トイレ」を追加） | +0.08 |
| ベッドがある | +0.05 |

| 屋根がかかっていない | −0.30 |
| 2階があるのに階段がない | −0.30 |

### 立地（土地を買うときに選ぶ）

| 立地 | 土地の基準 | 建物の査定 |
|---|---|---|
| 郊外の住宅地 | 500万円 | ×0.9 |
| 静かな住宅街 | 1,200万円 | ×1.0 |
| 駅近 | 2,500万円 | ×1.15 |
| 都心の一等地 | 6,000万円 | ×1.3 |

売り土地は毎日入れ替わります。土地は何か所でも持てて、「持っている土地」から行き来できます（土地ごとに設計図が別々に残ります）。最後の土地を売ると、画面の設計図だけが手元に残り、次に買った土地でそのまま建てられます。

## カジノ・競技場

カジノは土地の前の道路をはさんだ向かい側に、最初から建っている施設です。プレイヤーの家の部品ではないので、削除ツールで消したり、上に建てたりはできません。

- 遊べるのはカジノの中だけです。歩きモードで入口（赤いじゅうたんの先）に近づくと自動ドアが開き、そのまま歩いて中に入ります。店の奥へ進むか入口から離れると自動で閉まり、また近づくと開きます。不動産屋・車屋も同じで、別の場所へは移動しません。
- 上のバーの「🎰 カジノへ行く」を押すと、歩きモードになって入口の前へ移動します。
- スロット・ルーレット・ハイ＆ローの台は3Dです（家と同じ Three.js）。スロットは赤い台の両どなりにも台が並び、ガラスの奥でリールが回ります。ルーレットは木のボウルで盤が回り、玉が溝を逆向きに走ってポケットに落ちます。ハイ＆ローはフェルトのテーブルで、山札からカードが滑ってきてめくれます。カジノを開いている間は、後ろの世界の描画を止めて軽くしています。
- 声：競馬・競輪・ボートの実況をアナウンサーの声で読み上げ、ルーレットではディーラーが「ノー・モア・ベット」や出目を読み上げます（ブラウザの読み上げ機能）。iPhone はマナーモードでも鳴るように、画面に触れたときに読み上げと音の再生を準備します。日本語の声が入っていない端末では読み上げず、画面に「字幕だけ」と出します。話している途中に次の実況が来たら、話し終わってから最新の1つだけを読みます。
- 遊び方：各ゲームの上に「📖 ○○の遊び方（はじめての方へ）」があり、ルール・賭け方・配当と当たりやすさ・はじめての方へのコツを読めます。はじめて開いたゲームでは開いた状態で、2回目からはたたんであります（`src/ui/casino/Guide.tsx`。倍率や確率はゲームの設定から計算）。
- 中の画面は緑のフェルトと金のカジノ風。賭け金は色分けされたチップ（1千・1万・10万・100万・1千万）を積んで決めます。効果音と声つき（右上の 🔊 で消せます）。
  - スロット：リールが回って左から順に止まり、そろうと払い出しのランプとコインの演出（×15 以上は BIG WIN、×200 以上は JACKPOT）。レバーを引いても回せます。
  - ルーレット：本物と同じ並びのホイールに玉を投げ、台（0、数字、列、ダース、赤黒・奇数偶数・前半後半）にチップを何か所でも置けます。右クリックでそのマスのチップを外せます。「前回と同じ」で同じ置き方をくり返せます。
  - ハイ＆ロー：山札からカードがめくられ、連勝数と持ち分、次に当てたときの額が出ます。
- 建物の壁・柱・植え込みにはぶつかります。場所と大きさは `src/building/landmarks.ts`、見た目は `src/world/CasinoBuilding.tsx` にあります。

賭け金に上限はありません（所持金まで）。どのゲームも長く続けると少し損をするように作ってあり、バイトの価値を守ります。

| ゲーム | 遊び方 | 還元率 |
|---|---|---|
| スロット | 3本のリール。7・BAR・ベル・スイカ・レモンの3つそろい、左のチェリーで元返し | 93.5% |
| ルーレット | ヨーロピアン（0〜36）。赤／黒、奇数／偶数、前半／後半（×2）、ダース（1〜12 など）・列（×3）、一点（×36） | 97.3% |
| ハイ＆ロー | 次のカードが大きいか小さいか（同じ数字は負け）。倍率は当たりやすさで決まり、当てたらそのまま続けて倍々に挑める | 95% |
| 競馬 | 8〜18頭立て。芝・ダート、1200〜2400m | 72.5〜80% |
| 競輪 | 7車・9車立て、2025m（5周） | 75% |
| ボートレース | 6艇立て、1800m（3周） | 75% |

### 公営競技（競馬・競輪・ボートレース）

実際の券種・買い方・払戻率に合わせています。

| | 券種と払戻率 |
|---|---|
| 競馬（JRA と同じ） | 単勝・複勝 80%、枠連・馬連・ワイド 77.5%、馬単・3連複 75%、3連単 72.5%。複勝は8頭以上なら3着まで、7頭以下なら2着まで |
| 競輪 | 2枠複・2車複・2車単・ワイド・3連複・3連単（単勝・複勝はない）。すべて 75% |
| ボートレース | 単勝・複勝（2着まで）・2連複・拡連複・2連単・3連複・3連単。すべて 75% |

- **買い方（自動発売機）**：実際の券売機と同じく「式別 → 方式 → 番号 → 金額 → 確認・セット」の順に押し、セットした分は右の「投票内容」にたまります（1件ずつ取り消し可）。「購入する」でまとめて支払い、紙の券（馬券=緑・車券=赤・舟券=青）が出てきます。方式は通常・ボックス・ながし（軸と相手）、順番を問う券種はフォーメーションも。金額はテンキーで100円単位。枠連（2枠複）の通常は1つ目・2つ目の枠を1つずつ選び、2人以上いる枠は同じ枠どうし（ゾロ目）も買えます。買い目ができていないときは、あと何を選べばよいかが出ます。
- **出走表**：競馬は枠番（JRA と同じく、9頭以上は外の枠から2頭ずつ）・馬番・印・馬名・脚質・性齢・斤量・騎手・馬体重。競輪は府県・年齢・級班・脚質・競走得点と「並び予想」（ライン）。ボートは級別・支部・全国勝率・モーター2連率・展示タイム。単勝・複勝オッズと人気、券種ごとの人気順オッズも見られます。
- **確率とオッズ**：着順は「強さ」に比例した確率で1着から順に決まる模型で決め、この模型から全券種の確率を正確に計算して、オッズ = 払戻率 ÷ 確率（0.1倍単位で切り捨て、最低1.0倍）にしています。オッズどおりの当たりやすさになります。ボートは実際と同じく1号艇（1コース）が強く、1着率はおよそ半分です。
- **レース映像**：3Dのレース場を、テレビ中継のようなカメラで先頭集団を追いかけて映します（競馬・ボートは外側のスタンド側から、競輪はバンクの内側から）。馬は4本の脚でギャロップし、騎手は枠の色の帽子と勝負服。競輪はカントのついたバンク（直線9°・コーナー33°）を、ペダルをこぐ選手が傾いて走ります。ボートは曲がるときに内側へ傾き、白い引き波が広がって消えます。右上に全体図、「コース全体を見る」で上空からの眺めになります。競馬場は実際の周長と直線の長さ（東京・中山・阪神・京都・札幌・小倉、中山などは右回り）、ハロン棒、ゴール板。競馬はゲートから出て、逃げ・先行・差し・追込の脚質どおりに位置を取り、直線で着順が決まります。競輪は400m／333mバンクで誘導員の後ろを一列で周回し、打鐘（残り1周半）で一気にスピードが上がります。ボートは助走してスタートラインを通過（スタートタイミングつき）、ターンマークで減速して回り、引き波が残ります。
- 実況（スタート、位置取り、最後の直線、打鐘、1周1マーク、ゴール）、残り距離・残り周回、通過順、コース全体図が出ます。再生の速さは ×1（実際の時計）〜×8、コース全体表示、結果まで飛ばすこともできます。
- 結果は着順とタイム・着差（ハナ・クビ・1/2…、競輪は車輪・車身、ボートはスタートタイミングと決まり手）、払戻金（100円あたり・人気）の掲示板で出ます。
- 1レースで何点でも買えます。レースの途中でメニューを閉じても払い戻しは受け取れます。走る前に閉じた券は返金されます。

## 町とマップ・ワープ

- 町は1本の大通りに沿って区画が並ぶ。西から「静かな住宅街」「郊外の住宅地」「駅近」「都心の一等地」の4地区で、各6区画。はじめの土地は郊外の0番で、道路の向かいがカジノ・競技場。
- 土地を買うと、その立地の空いている区画に決まる（売り土地にも区画があり、町に「売地」の看板とロープが立つ）。区画のない古いセーブの土地は、読み込むときに自動で区画を割り当てる。
- 3D の世界では、いま建てている土地をいつも原点に置き、ほかの持っている家・売り地・カジノは区画の差だけ横にずらして描く。ほかの土地の家は見えてぶつかるが、中に入ったり建てたりするのはその土地へワープしてから。
- 🗺 マップ（M キー、スマホは左上の「マップ」）で町全体を見られる。持っている土地を選ぶと「ここへワープ」、売り土地はその場で買える、カジノは入口へワープ。

## バイト

「💼 バイト」ボタン（上のバー・地図・不動産屋の家計簿）から、ミニゲームのバイトを1シフトずつ働けます。給料は「基本給＋できた件数×出来高−ミス×減額」で、最低保証があります（`src/economy/jobs.ts` の `JOBS`）。

| バイト | 作業 | 時間 | 基本給＋1件 |
|---|---|---|---|
| コンビニのレジ | 商品をスキャンし、お預かりからおつりを硬貨・お札で渡す | 60秒 | ¥6,000＋¥2,500 |
| 倉庫の仕分け | 伝票の住所（都道府県）を見て地域のカゴへ | 45秒 | ¥4,000＋¥900 |
| ハンバーガー屋 | 注文票（〇〇抜きもある）どおりに具を積む | 60秒 | ¥5,000＋¥2,000 |
| 交通量調査 | 通る車を5種類のカウンターで数える（終わりに答え合わせ） | 30秒 | ¥8,000＋¥300 |

## セーブ

お金・土地・建った家・相場・家計簿はブラウザ内（localStorage の `open-world:economy:v1`）に自動で保存されます。「家計簿・バイト」の一番下で、お金と土地を最初からやり直せます。セーブスロット（設計図の保存）はこれまでどおり使えます。読み込むのは設計図だけなので、お金は変わりません。

## まだ入っていないもの

- 建てる前（未着工）の部分を3Dで半透明に見せる表示
- 築年数による値下がり、土地の広さの違い、ワールド上に複数の土地を並べる表示
- 数値のバランス調整（遊んでみてから）
