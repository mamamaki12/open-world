# ログアウト中の車を消し、入り直したら決まった場所に置く

状態: 実装中
ブランチ: `claude/project-thread-d8pxgt`

## 目的
みんなのワールドで、持ち主がログアウトしている車はワールドに出さない。入り直したときは、自分の土地の前の道路（土地がなければ車屋の横の駐車場）に車を置く（しんご 2026-11-08）。

## やり方
- 非表示：ほかの人の車は、その人が送ってくる位置情報（pose）の中にしかない。中継サーバーは接続中の人だけを参加者として送り、画面は参加者でない人の pose を消すので、ログアウトすると車も消える（今の仕組みのまま。確認だけする）。
- 入り直したときの配置：`src/session/session.ts` の `showAccount`（入場時に1回だけ車を復元する所）で、口座に残っていた最後の座標を使わず、`src/world/carSpawn.ts` の `spawnCars` で置き直す。
  - 自分の土地（町の家・お店でも自分のものなら可）があれば、その土地の南側（土地の正面）の道路の土地側の車線に、東向きで縦に並べる。
  - 置ききれない分や土地がない人は、車屋の横の駐車場（DEALER_BAYS）の空いている区画へ。
  - ほかの人の車がいる場所は避ける。
- 通信が一瞬切れて再接続しただけのときは置き直さない（入場時だけ）。自分のワールドは今までどおり。
- 中継サーバーは変えない（EC2 の更新はいらない）。

## 進み具合

- 次：spawnCars とテスト、showAccount から呼ぶ、ブラウザーで確認
