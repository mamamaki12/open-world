## 方針

- 問題（2026-11-10 にスマホ横 844×390 で撮って確認）
  - カジノ：上に所持金・戻る・遊び方が縦に積まれ、台はその下で上の端しか見えない。スロットの「レバーを引く」・ルーレットの「スピン」・ハイ＆ローの「ハイ／ロー」は下に固定されていて台に重なる。競馬・競輪・ボートは出走表と券売機が縦に並び、券売機は何画面も下。
  - バイト：一覧を下までスクロールしてから仕事を選ぶと、そのままの位置から始まり、残り時間・「やめる（給料なし）」・問題の上が切れる（倉庫の仕分け・ハンバーガー屋）。パネルの幅が 720px までで、答えのボタンが問題の下に縦に積まれる。
- 対象はスマホの横向きだけ（`.touch` かつ `orientation: landscape` と `max-height: 500px`。ほかの横向きの決まりと同じ）。縦向き・タブレット・PC は変えない。
- カジノ（6種とも）
  - 左の列：上に「戻る・所持金・遊び方・音」の1行、その下に台（スロットのリール、ルーレットの盤と出目、ハイ＆ローのカードの台、競技場の出走表・レース映像）。台の3Dは列の高さいっぱいにする。
  - 右の列：賭け金・チップ・回すボタンなど。上から下まで使い、中だけスクロールする。スロットの「レバーを引く」、ハイ＆ローの「ハイ／ロー」、競技場の「レースを観る」は列の中に見えるようにする。
  - ルーレットは右の列を広めにして、1行目に「チップ5枚＋スピン」、その下に賭け台。「1つ戻す・クリア・×2・前回と同じ」と「チップを外すモード」は賭け台の下。
  - 競技場は左右の列をそれぞれ白い紙にする。レース中は今までどおり全画面の映像。終わったら左に映像、右に払戻。
  - 所持金の「所持金」の文字と、遊び方の「開く ▼」は、横向きでは幅が足りないので省く（金色の金額と本のアイコン＋「遊び方」は残す）。
  - 作り：各ゲームの部品に「台の包み（casino-table-side）」と「操作の包み（casino-side）」を足す。ふだんは `display: contents` で無いのと同じにし、縦向き・PC の並びは変わらない。
- バイト（4種とも）
  - 上の行に残り時間と件数。「やめる（給料なし）」は文字を残し、左上に置いて、右の列の答えのボタンから離す。
  - その下を左右2列：左に問題（レシート・荷札・注文票と作っているバーガー・道路）と正解／ミスの一言、右に答えのボタン（お金・地方・具・数えるボタン）。シフト終了の給料のカードは右の列に出す。
  - パネルは横幅いっぱいにする。
  - 仕事を選んだら、パネルの中を一番上に戻す（向きに関係なく。一覧をスクロールしてから選んでも、残り時間と「やめる」が見える）。
  - 作りはカジノと同じく「問題の包み（job-question）」「答えの包み（job-answers）」を足し、ふだんは無いのと同じにする。
- 使い方の改善で新しい機能ではないので、version は変えない（docs/versioning.md の PATCH）。
