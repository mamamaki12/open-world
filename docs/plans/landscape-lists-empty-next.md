## 方針

- 問題（2026-11-12 に #176 の版で撮って確認）
  - 横向きのスマホ（844×390）で、一覧の前の飾りが画面を埋める。車のカタログは見出し「お気に入りの一台を。」と絞り込みで車が見えない。車の詳しい画面は 3D の絵の下に値段があり、同時に見えない。バイトの一覧は1件ずつ。服の店・クローゼットは見出しの帯で上半分が埋まる。
  - ひとりで遊ぶときの「仕事の依頼」「家のランキング」、車がないときの「カーカスタム」は、説明が1行あるだけの空の画面で、次にどこへ行けばいいか分からない。
  - 見た目を変える・美容室で、「決定」「この髪型にする」が横向きと 320×568 では下まで動かさないと見えない。
  - スロットの「賭け金」の文字が暗い緑の台の上で濃い緑になり、読めない。
  - 家具をデザインの閉じるだけ、スマホでも「✕ 閉じる」と文字付き（ほかのパネルは ✕ だけ）。部品を足すボタンの読み上げの名前が全部「拡大」になっていた。
  - カジノのロビーの札「このゲームで遊ぶ ↗」の斜めの矢印が、外のページへ移る印に見える。
- 直し方（CSS が中心。データ・計算・保存の形は変えない）
  - 横向き（`orientation: landscape` かつ高さ 500px 以下）だけ：
    - 車のカタログ：見出しは読み上げにだけ残し、絞り込みと件数・リセットを1行に。車のカードは左に絵・右に名前と値段の横長で2列（「詳しく見る」の行は畳む。カード全体が押せる）。詳しい画面は「一覧」と車名を1行に、絵（左）と値段・購入（右）を並べる。`DealerPanel.tsx` に包み（`catalog-toolbar`・`catalog-detail-top`）を足し、ほかの画面では `display: contents` で無いのと同じ。
    - バイト：一覧を2列にし、説明と「プレイヤーからの依頼を見る」を1行に。4つの仕事が最初の画面に収まる。
    - 服の店・クローゼット：見出しの帯を1行（見出しと所持金）に畳み、服は3列・正方形の絵に。
  - 空の画面：依頼（ひとり）は「バイトを探す」「建築の依頼を見る」、ランキング（ひとり）は「家を建てる」「建築の依頼を見る」、カーカスタム（車なし）は「車屋の前へ行く」（`warpToVenue('dealer')`）。説明に「開始画面の『みんなのワールドで遊ぶ』から入れます」を足す。建築の依頼はひとりのときだけ受けられるので、オンラインのときはそのボタンを出さない。ボタンの間は 8px。
  - 見た目を変える・美容室：お会計と決定の帯（`.looks-actions`）を画面の下に止める（`position: sticky`）。横向きは左の絵を画面の高さに収めて止める。
  - スロットなどの「賭け金」の文字は、所持金の札と同じ金色（`#e6cf98`）。
  - 家具をデザインの閉じるは、ほかのパネルと同じ `IconLabel`（スマホは ✕ だけ・PC は「✕ 閉じる」）。読み上げの名前「閉じる」は残す。部品を足すボタンの読み上げは「板を足す」など。
  - カジノの札の矢印は → に（`iconText('→')` の右向きのアイコン）。
- 使い方の改善と見た目の直しで新しい機能ではないので、version は変えない（docs/versioning.md の PATCH）。
- やめたもの：なし。
