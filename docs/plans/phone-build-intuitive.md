## 目標

スマホ（縦 390x844・横 844x390、?touch=1）の建築画面で、迷う・押し間違える所をなくす（しんご 2026-10-24「操作感が直感的でない。問題点を探して改善まで」）。画面の部品は増やしすぎない。

## 点検で見つけた問題

1. 右上のカメラボタン「左に回る」が、左上の「取り消し」と全く同じ矢印アイコン（AppIcon の ⟲ が undo に割り当て）。「右に回る」も反時計回りに見える丸矢印で、向きが逆に読める。
2. 道具を持つと、左上の取り消し・やり直しに文字が付いて縦画面では2段に折り返し、地面を隠す。
3. 道具をしまう（手ぶらに戻る）には「建てる」→全画面メニュー→「道具をしまう」の3手。
4. 道具を持った状態でメニューを開くと、縦画面では道具カード11枚の下に種類・素材が隠れ、毎回スクロールが必要。
5. 壁・床・屋根をなぞっている間、指で隠れて長さ・広さが分からない。置けない所でも理由が離すまで分からない。

## やること（方針）

1. カメラの回転ボタンを「家のまわりを回る」専用アイコン（orbitLeft / orbitRight）に替える。
2. 縦画面（幅 480px 未満）では取り消し・やり直しの文字を出さず、1段に収める。
3. 建築画面で道具を持っているとき、「建てる」ボタンの角に小さな ✕（手ぶらに戻る）を付ける。歩き画面は別スレッドが作業中なので触らない。
4. 縦画面で道具を選んでいるときは、道具カードを説明なしの小さな並びに縮め、種類・素材がすぐ見えるようにする。
5. なぞっている間、画面上部に「長さ 3.64m」「2.73m × 3.64m」のような寸法チップを出す（置けないときは赤で「ここには置けません」）。
