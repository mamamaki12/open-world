# 移動中の画面ダブルタップでジャンプ

- ブランチ: `feat/moving-double-tap-jump`
- 依頼: 歩行・走行中、ボタンのない画面を2回タップすると移動しながらジャンプ。

## 方針
- Playerのキャンバスタッチに短い2連続タップを追加。スティック入力と水平速度を維持。
- スワイプ・ピンチ・キャンセル・UI・建築操作・運転・着席・メニューでは発火させない。
- ジェスチャー判定を単体検証し、歩行・走行しながらスティックを離さずタップするブラウザ検証を追加。
