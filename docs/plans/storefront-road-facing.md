# デフォルト店舗の入口を道路側へ向ける

- ブランチ: `codex/appearance-onboarding`（mamamaki12/open-world）
- PR: #96
- 依頼: デフォルトの店に道路と反対側を向いているものがあるため修正する。

## 方針
- 道路に背を向けていた北側のmaison・urbanを180度回転する。
- 外観だけでなく遠景・内装・自動ドア・通路・家具の衝突・店内操作位置の向きを統一する。
- 店舗の敷地と利用者の建築・保存形式は維持する。
