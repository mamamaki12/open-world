# 共有ワールドの新しい入室で古い接続を終了する

- ブランチ: `codex/shared-ui-qa`（mamamaki12/open-world）
- 依頼: 新規入室時の「すでに別のブラウザで参加しています」を解消する。

## 方針
- 新しい明示的な入室は古い接続を終了して同じゲストを引き継ぐ。自動再接続では他の画面を追い出さない。
- 削除するのは古い接続情報。共有の町・家・土地・所持金・服・個人ワールドは保持する。
- 追い出された画面は保存を止め、古いセーブで新しい画面を上書きしない。開始画面へは再読込して戻る。
- relay統合と同じ保存データを使う2画面で、切替・旧画面の停止・人数重複なし・保存維持を検証する。
- server/dist/relay.mjsも更新する。本番のEC2中継更新が必要。こちらにはSSH接続手段がないため、既存のWORLD_FILEを維持する更新手順を用意する。

## 進捗
- 済: server/relay.mjsの共有入室処理が既存socketを一律拒否することを確認。
- 済: UI総点検の修正後、型チェックと追加のブラウザ回帰が成功。
- 次: takeover指定・旧接続の書込み停止・サーバーとブラウザ回帰を実装する。
