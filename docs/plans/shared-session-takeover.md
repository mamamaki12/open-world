# 共有ワールドの新しい入室で古い接続を終了する

- ブランチ: `codex/shared-ui-qa`（mamamaki12/open-world）
- PR: #93
- 依頼: 新規入室時の「すでに別のブラウザで参加しています」を解消する。

## 方針
- 明示的な新しい入室だけが古い接続を終了して同じゲストを引き継ぐ。自動再接続では他の画面を追い出さない。
- 古い接続情報・描画を終了し、共有の町・家・土地・所持金・服・個人ワールドは保持する。
- 旧画面は`sessionGate.superseded`で保存と保存待ちを止め、古いセーブで新しい画面を上書きしない。開始画面へは再読込して戻る。
- `server/dist/relay.mjs`も更新。本番はEC2中継の更新が必要。SSH手段がないため、既存WORLD_FILEを維持する更新コマンドを案内する。

## 進捗
- 済: 実装前に計画をcommit/push。relayの共有入室が既存socketを一律拒否することを確認。
- 済: 新規入室のtakeover指定、旧接続の終了・遅延フレーム拒否、自動再接続による奪い返し防止を実装。
- 済: 旧画面のAppをアンマウントし描画を解放。保存と保存待ちを無効化し、旧画面の戻る操作はreloadに変更。
- 済: relay統合5件、保存停止の単体1件、型チェック成功。
- 済: Chromeで同じIndexedDBの2タブと、セーブをコピーした独立ブラウザ保存環境を検証。所持金・個人ワールド保持、人数1、旧画面のcanvas除去、古い画面からの保存上書き防止、旧画面の再読込が成功。
- 次: 最終CIとPages公開確認。本番EC2で`scripts/update-relay-amazon-linux.sh <revision>`を実行する必要がある（既存の保存先と設定は保持）。
