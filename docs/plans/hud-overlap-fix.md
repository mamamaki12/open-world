# 画面の要素が重なる不具合をなくす

状態: 作業中
ブランチ: `claude/project-thread-9usabv`
残作業: 洗い出し → 修正 → 検査スクリプト
確認根拠: （未）

## 目的
しんご 2026-11-09「要素が重なる不具合を無くしてほしい」。スマホ横画面の歩く画面で、家具を持つと右側の「配置」ボタンに 👥人数チップが重なっていた（スクショ）。スマホ縦横・PC（文字200%）でHUDの重なりを洗い出して直す。

## やり方
- みんなのワールド（ローカル relay）に入り、歩く画面で道具（家具・階段・壁・削除）を持った状態と建築画面を、スマホ縦横・PC各サイズで `check-large-text.mjs` と同じ重なり判定にかける新スクリプト `scripts/check-hud-overlap.mjs` を作る。
- 見つかった重なりをCSSで直す（配置・回転ボタンは👥チップより下から並べる、など）。
- 既知：PC文字200%で日付変更のお知らせがボタンに重なる（CIの large-text でたまに出る）。

## 追加の要望（しんご 2026-11-09）
「配置ボタンはいらないから十字のカーソルタップしたらその場所に配置」→ 床・壁・家具などを持っているときの「配置」ボタンを消す（スマホは十字タップ、PCはクリック）。削除だけは誤操作を防ぐため「長押しで削除」ボタンを残す。

## 見つかった重なりと直し方
- スマホ横：👥チップ × 配置 → 配置ボタン自体を消した（回転だけ残る）
- スマホ縦320：照準の説明 × 配置 → 360px以下は説明を照準の上に
- スマホ横（低い）の建築画面：上の操作説明 × 取り消す/やり直す → 横向きは取り消し・やり直しを記号だけに、幅720px以下は操作説明を出さない
- PC：照準の操作説明（aim-mouse-help）× 道具バー → 道具バーの高さ（--quick-tools-h）の上に
- PC 幅900px以下（文字200%）：右下の👥チップ × 道具バー → 道具バーの上に

- 済：計画、洗い出しスクリプト scripts/check-hud-overlap.mjs（重なり判定は scripts/layout-scan.mjs に切り出し、large-text と共用）、上の直し
- 次：再スキャン、既存の検査（aim-controls・furniture/interior-lighting）を十字タップに直したので通るか確認、CIに追加
