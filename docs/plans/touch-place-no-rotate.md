# スマホで配置中は画面を回さない

- 状態：公開待ち
- 残作業：PRのCIとマージ
- 確認根拠：`scripts/check-touch-place-no-rotate.mjs`（壁の上端で屋根をなぞってもカメラが動かず屋根が置ける・土地の外から触れた指は回る）。修正前のコードでは失敗（カメラが14.7m動いた）を確認。check-phone-build-ux / check-build-controls / check-aim-controls も通過
- ブランチ：`claude/project-thread-hu5kh0`
- 依頼：しんご 2026-11-07「床・壁・屋根を配置するとき、場所をタップして青くなったら画面の回転を無効にしてほしい」

## 原因（調べた結果）
- 1本指で「置く」か「回す」かは `BuildCamera.tsx` の pointerdown で決めていた（`touchGesture.reserved`）。
- そこでの「土地の中か」の判定が、実際に置く位置（`PlacementController.tsx` の `surfaceAt`）と違っていた。特に屋根は壁の上端の高さで読むのに、判定は今の階の高さで読んでいたので、斜めから見ると「土地の外」と判断されて回転になっていた。
- そのとき `activeTouch` だけは入るので、指に合わせて青いプレビューが出たまま画面が回っていた。

## 方針
- 判定を `PlacementController` に移し、置くときと同じ面・同じ点で決める。土地の端から1マスは土地の中とみなす（置く位置は土地の中に寄せられる）。
- 予約されなかった指では青いプレビューを出さない（回すだけの指で青くならない）。
- 置いている途中（指を離すまで）は1本指の回転をしない。2本指で触ったら今までどおり配置をやめてカメラ操作。
