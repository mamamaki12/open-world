# 共有ワールド更新の直列化（実装方針と進捗）

- ブランチ: `codex/fix-verified-gameplay-bugs`
- 依頼: 保存中の日替わりで家賃精算が消える不具合を修正。

## 方針
- `server/relay.mjs` の時計・口座作成・取引を同じqueueに直列化し、永続保存成功後にworldを確定・配信する。保存失敗では前の状態を保持する。
- 保存待ちに日替わりと新規参加を重ねる回帰テスト、家賃残高・永続保存・再起動の検証を行い、`server/dist/relay.mjs`を再生成する。
- 公開済みEC2の更新は別途必要。本作業はdraft PRまでとし、本番保存を変更しない。

## 進捗
- 済: 最新mainと関連plans確認。rename待機中に家賃精算が失われる再現を確認。実装前の計画作成。
- 次: 計画をcommit/push後、直列化と回帰検証。
