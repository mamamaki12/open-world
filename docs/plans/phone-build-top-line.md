# スマホ建築中の上部の緑の線を消す

状態：完了（PR作成・CI待ち）
ブランチ：claude/project-thread-34gjyb
依頼：しんご 2026-11-08「スマホの画面で建てるで床とか選択したときに画面上部に緑の横線が表示される」

## 原因
- スマホ横画面で道具を持つと、`.quick-tools`（上の帯）の中身が「取り消す・やり直す」だけになり、それが `position:absolute` で右へはみ出す。帯の枠（濃い緑の2px線＋影）だけが中身0の高さで残り、横線に見えていた。
- はみ出した「取り消す・やり直す」が右上の 👥 や「始点を決める」と重なっていた。

## やり方
- スマホでは `.quick-tools` 自体の枠・背景を消す（中のボタンは自分の枠を持つ）。
- （しんご 04:27・04:35）中央は目立つので、スマホで道具を持っている間は「取り消し・やり直し」をアイコンだけの小さな丸ボタンにして、右上の地図ボタンの左に置く（.touch-history、src/ui/App.tsx の MapButton）。中央の帯（BuildHistory）はPCだけ。
