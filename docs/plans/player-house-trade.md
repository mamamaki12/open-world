- PR: （出したら書く）

## 方針
- 同じ部屋（ホスト＋ゲスト最大4人）にいる間だけ、自分の**自宅ワールド**の土地（家ごと）を相手に値段を付けて売れる。ホスト→ゲスト、ゲスト→ホスト、ゲスト同士のどれでも可。
- 中継: `server/relay.mjs` に `trade`（指定した相手へ転送、送信者は中継が固定）を追加。**EC2の relay.mjs 更新と再起動が必要**。
- 手順: 売り手が申し込み（土地の中身・値段）→ 買い手が承諾時に代金を仮払い → 売り手が土地を自宅から外して代金を受け取り保存 → `sold` を返す → 買い手の自宅に土地を追加。断り/失敗/切断は買い手へ返金。
- 買い手の自宅で同じ区画が空いていればそこ、埋まっていれば同じ立地の空き区画へ（つなげた土地は同じ2区画が空いているときのみ）。工事中の土地は売れない。
- 実装: `src/session/trade.ts`（自宅の土地の読み書き・取引）、`session.ts` の受信に `trade` を接続、UI は部屋メニュー（`SessionRoot.tsx`）。価格計算（`src/economy/pricing.ts` など）は別スレッドが変更中なので触らない。既定の値段は現在の売却額。
- テスト: `src/session/trade.test.ts`（区画の決め方・検証）、`server/relay.test.mjs` に転送テスト。

## 進捗
- 済: 中継サーバーの仕組みを調査（ホストが世界を確定、ゲストの資産は端末保存を信頼）。方針を決定。
- 次: 中継の `trade` 追加 → trade.ts → UI → テスト → PR。
