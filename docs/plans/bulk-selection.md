# まとめて選ぶ操作の修正（実装方針と進捗）

- ブランチ: `codex/fix-bulk-selection`（mamamaki12/open-world）
- 依頼: 「まとめて選択する機能が全然使えない」

## 方針
- 削除ツールの「まとめて選ぶ」と「同じ素材・色をまとめて移動」の両方を修正（追加確認への回答：両方）。
- `src/world/PlacementController.tsx`、`parts/usePart.ts`、`BuildCamera.tsx` の操作を整合させる。選択だけでは削除せず、確定して一括削除・1回で取り消せるよう維持する。
- PC／スマホのクリック・タップ、範囲指定、解除、削除・取り消しとツール切替を検証する。土地の編集権限・共有データを維持する。
- 追加依頼「PCでドラッグしても1個選択したまま」への対応として、選択ツールに明示的な範囲選択を追加する。範囲指定と移動を分離し、選択数を示す。任意の複数パーツの移動・削除を1回で取り消せるようにする（次に実装）。
