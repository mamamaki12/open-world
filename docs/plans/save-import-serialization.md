### 方針
- importは通常保存と同じ直列化を通し、復元中の自動保存では古いスナップショットを作らない。保存失敗時は現在のデータを保持する。
- 古い保存を待機させてimportと自動保存を重ねるテストで競合を再現し、復元データが再読み込み時にも残ることを検証する。
