# バックアップ復元と自動保存の競合

- ブランチ: `codex/fix-verified-gameplay-bugs`
- PR: #87（draft）
## 方針
- importは通常保存と同じ直列化を通し、復元中の自動保存では古いスナップショットを作らない。保存失敗時は現在のデータを保持する。
- 古い保存を待機させてimportと自動保存を重ねるテストで競合を再現し、復元データが再読み込み時にも残ることを検証する。
## 進捗
- 済: 通常保存は`saving`に並ぶが、importだけが直接`writeSave`することを確認。
- 済: 計画を先にpush。保存を待機させた回帰テストで、復元した999円が古い100円で永続保存されることを確認（修正前は失敗）。
- 済: importを保存queueへ統合し、復元中の自動保存は復元後にsnapshotする。復元失敗でも元のデータを保持する。復元の4テスト成功。
- 次: ブラウザーimport/reloadと全体検証。
