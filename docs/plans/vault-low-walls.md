# 低い壁をジャンプで越える

- 状態: 実装中
- ブランチ: `claude/project-thread-p4u63z`
- 依頼: しんご 2026-10-21「低い外壁や1/2の壁をジャンプで超えられるようにして」

## 原因
ジャンプの高さは約0.9m（JUMP_SPEED 4.2）。塀（fence）は地面から1.2m、1/2の壁は床(0.5m)+1.45m で上端1.95m。
壁の当たり判定は足が上端を越えるまで効くので、どちらも越えられない。

## 方針
- `src/building/walk.ts` に `vaultWallAhead()`：進む向き（止まっていれば体の向き）の前 0.6m 以内にある
  低い壁（fence / half）の上端を返す（足からの高さ 2.1m まで）。
- `Player.tsx` の jump：前に低い壁があれば、上端+0.2m まで届く上向きの速さで跳び、止まっていれば前へ少し押し出す。
  キー（Space）もスマホのスティック2回タップも同じ jump を通るので両方に効く。
- 目隠しフェンス(1.8m)・ふつうの壁は対象外。
