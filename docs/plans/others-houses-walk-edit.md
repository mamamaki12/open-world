しんご（2026-10-23）「他人の家だと床の上に上がれない・ドアを開けるボタンが出ないバグがある。誰の家でも上がれて、ドアの表示ができるように。他の人の家を編集できない制限もいらないので外して」

## 原因

- `src/world/visit.ts` の `visitAt` は町に最初から建っている家（TOWN_HOUSE_PLOTS）だけを「訪ねる家」として扱う。
  いま編集していない土地（共有ワールドの他プレイヤーの土地、自分のほかの土地）は対象外なので、
  床・階段の高さもドアの判定も自分の家で計算され、床に上がれずドアのボタンも出ない。
- `src/world/Player.tsx` の `resolveTown` は、ほかの土地の家をドアがいつも閉まっている扱い（`() => false`）で当たり判定している。
- 編集は `canBuildOn`（src/server/sharedWorld.ts）で持ち主と「一緒に建てる人」（PR #95）だけに制限。

## 方針

1. `visitAt` を、いまの土地以外のすべての土地の家（`lotHouse`）にも広げる。ずらした家はキャッシュ（家オブジェクトが変わったら作り直す）。
2. `resolveTown` のほかの土地もドアの開閉（`isDoorOpen`）で判定。
3. `canBuildOn` を常に許可にする（クライアントとrelay両方）。「一緒に建てる人」の機能（UI・操作・CIチェック）は不要になるので外す。
   relay も変わるので EC2 の relay 更新が必要（server/README.md）。
4. 町に最初から建っている家の編集は別判断（しんごに確認中）。
