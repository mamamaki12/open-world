## 方針

- CSSは全てpx指定のため、ブラウザの既定文字サイズ設定では変化しない。実際に崩れるのはページ拡大（PCのCtrl+、iOS SafariのaA、Androidの表示サイズ）で、CSS上の画面幅が狭くなるのと同じ。
- Playwrightで deviceScaleFactor 付きの縮小viewport（PC 1280x720の150%/200%=853x480/640x360、スマホ390x844/844x390の150%=260x563/563x260）を作り、表示中のボタン・文字要素の矩形の重なり・画面外・文字の切れを検査する（scripts/check-large-text.mjs）。
- 見つかった箇所はCSSの折り返し・最小幅・スクロールで直す。ui-conventions（--top-h/--hud-top 使用）を守る。
