# PCの建物LODと室内・家具の距離制御

- ブランチ: `perf/desktop-building-detail`
- 依頼: しんご「①遠い建物の簡略化、②離れた建物の室内・家具を描画から外す。PCのみ」

## 方針
- PCのみ建物までの距離で近/中/遠を切り替える。境界に余裕を設け、往復時のちらつきを防ぐ。DPR・影・スマホ設定は変更しない。
- 町の住宅は近距離で従来表示、中距離で外観だけ、遠距離で外壁・屋根の輪郭を保つ簡略モデル。素材別ベイクに内外の分類を加える。
- 店舗は離れると室内・家具・マネキンを描画しない。遠距離は店舗の外形を保つ簡略モデル。現在訪問中の家・入店中の店・編集対象は詳細表示を維持する。
- 当たり判定・所有権・セーブのデータは維持。車カスタムショップの作業中PR #48と重なる店舗の変更を小さくする。
- 同一カメラの描画命令/三角形数を比較。距離境界、建物外形、接近/入店/訪問/編集、PCとスマホを単体/ブラウザで検証。
