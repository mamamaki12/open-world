## 方針
- 家具デザインを既存のoverlay状態へ統合して、ゲームショートカット・歩行・配置・ポインターロックをほかのモーダルと同じように停止する。
- 保存/配置/キャンセルでoverlayとdraftを同時に閉じ、選択物のDelete/UndoやTab/数字キーが背後に作用しないことを確認する。
## 進捗
- 済: デザイン画面を開いたままTabと3キーで、背後が建築→歩行、家具→壁に変わることをブラウザーで再現。
- 済: 計画を先にpush。designerをoverlay状態に統合し、キャンセル/保存/外部画面遷移でdraftを閉じる。背後の建築カメラもoverlay中は停止。
- 次: Tab/数字/Delete/Undoと保存/再表示をブラウザーで確認する。
