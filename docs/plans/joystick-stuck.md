## 症状（しんご 2026-11-10）
スマホでスティックを倒したまま指を離しても、つまみが戻らずプレイヤーが歩き続ける（高頻度）。地図を開いて閉じると直る（スティックが一度消えて作り直されるため）。

## 原因の見立て
`src/ui/TouchControls.tsx` の Joystick は、スティックの要素に届く pointerup / pointercancel / lostpointercapture だけで指を離したと判断している。iPhone などで別の指（カメラ操作など）と同時に触ったときや、ジェスチャーの途中でこれらが届かないと、`pointer.current` が残ったままになり、次に触っても「使用中」として無視され、ずっと戻らない。

## 方針
1. window でも pointerup / pointercancel を受けて、追っている指なら離したことにする。
2. touchend / touchcancel で、スティックの上で始まった指が残っていなければ離したことにする（タッチイベントは確実に届くため）。
3. スティックを新しくタッチしたら、前の指が残っていても新しい指に切り替える（固まったままにしない）。
