## 依頼（しんご 2026-10-24）

- 削除は一つずつしかできないようにする。
- 削除を選んだら、1つ消した時点ですぐ元の画面に戻る。
- 削除は、通常の画面の「建てる」ボタンの上に少し小さいアイコンで置く。

## 方針

- 「まとめて選ぶ」と範囲（ドラッグ）での削除をなくす。削除は1回に1つだけ。
- 1つ消したら、削除を選ぶ前の道具（ふつうは手ぶら）に自動で戻す（store の `eraseReturnTool`）。
- スマホの「建てる」ボタンの上に小さな削除ボタン（歩く画面・建築画面の両方）。建築メニューの道具一覧からは削除を外す。
- 削除を持っているときにもう一度押すとやめる（元に戻る）。
- PCはホットバーの 9（削除）を残す。動きは同じく1つ消したら元の道具へ。
