## 依頼（しんご 2026-10-24）

- 削除は一つずつしかできないようにする。
- 1つ消しても削除モードのまま。削除アイコンをもう一度押したら元の画面に戻る（訂正）。
- 削除は、通常の画面の「建てる」ボタンの上に少し小さいアイコンで置く。

## 方針

- 「まとめて選ぶ」と範囲（ドラッグ）での削除をなくす。削除は1回に1つだけ。
- 1つ消しても削除のまま（しんご 2026-10-24 訂正）。削除ボタンをもう一度押すと、削除を選ぶ前の道具（ふつうは手ぶら）に戻る（store の `eraseReturnTool`）。
- スマホの「建てる」ボタンの上に小さな削除ボタン（歩く画面・建築画面の両方）。建築メニューの道具一覧からは削除を外す。
- PCはホットバーの 9（削除）を残す。
