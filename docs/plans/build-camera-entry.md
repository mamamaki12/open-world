# 歩行位置の近くから建築を始める（実装方針と進捗）

- ブランチ: `codex/fix-bulk-selection`（同じ建築操作の修正として対応）
- 依頼: 「建築タブに切り替えたら、目の前の土地ではなく、視点が遠い場所に飛ばされる」

## 方針
- `Player.tsx` 終了時に歩行前の古いカメラへ戻す処理を廃止し、現在のプレイヤー位置・向きの少し先を注視する建築カメラへ移す。
- プレイヤー位置や土地の所有・編集対象を勝手に切り替えず、カメラと OrbitControls.target を同時に更新する。
- 移動先・異なる向き・高い階での座標計算と、遠くまで歩いた後の建築切替をブラウザで検証する。

## 進捗
- 済: `Player.tsx` がマウント時の古い建築カメラ位置を保存し、歩行終了時に復元する原因を特定。
- 次: 現在位置を基準に切替処理を修正・検証。

## 引き継ぎ
- `src/world/buildCameraPose.ts`、同test、`Player.tsx` の現在地を基準とした変更はローカルに実装済み（未push）。方角4通り・遠い座標・高い階の単体検証は成功。
- 実ブラウザでの建築モード切替は未完了。exec-server接続切断のため、bulk-selection.md の手順から復旧して検証・pushする。
