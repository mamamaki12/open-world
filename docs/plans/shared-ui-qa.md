# 共有ワールドを2ブラウザで点検（実装方針と進捗）

- ブランチ: `codex/shared-ui-qa`（mamamaki12/open-world）
- 依頼: 2つのブラウザで実際に遊び、UIの不具合を確認・修正する。

## 方針
- 最新mainを基準に独立したChromeクライアント2つで参加・移動・入店・地図・買い物・建築・退出・再接続を確認。
- PCとスマホ縦横を画面撮影し、重なり・操作不能・誤表示を再現してから修正する。
- 公開版は接続確認、購入・建築はローカル専用relayで行う。未公開PR #87の修正と重複する問題は明記する。
- 修正の回帰検証と型チェック・既存テストを行い、CI成功後に公開する。

## 進捗
- 済: main d51a8bdと未公開draft PR #87を確認。既存UI点検記録を確認。
- 済: 独立したChromeプロセス2つで同時参加、PC 1280×800・スマホ390×844で参加者一覧と11種類の画面を開閉・撮影。JS例外なし、ダイアログ横はみ出しなし。
- 発見: スマホの共有建築中は参加者パネルが隠れ、セーブにも退出ボタンがない。歩行モード経由でしか退出できない。
- 発見: 参加者パネルが無料建築なのに「建築費は本人が支払う」と案内する。
- 確認対象: 土地なしで「すぐ建つお店」を押すと配置されない。`submit`が通知せずreturnし、`placeShop`は成功表示を出す。拒否結果も参加者パネル内だけなので建築中に見えない。
- 方針追加: PR #87の地図所有表示だけを今回へ取り込み、サーバー更新待ちの修正と切り離す。元のdraftはサーバー変更を含むためそのまま維持する。
- PR: #93（draft、検証中）。退出導線・無料建築の案内・土地なしと建築拒否の通知・未確定時の成功表示抑制・地図所有表示を実装。
- 済: 修正後の2ブラウザで移動の伝達、土地購入のUI、店舗プレハブの伝達、他人の土地での拒否通知を確認。公開サイトでも2クライアント同時参加・互いの名前の表示・退出が成功。
