## 方針
- 時刻・季節・天気は **実時間（UTC の Date.now()）だけから計算**する純粋関数 `src/world/climate.ts`。保存もサーバーも不要で、共有ワールドの全員が同じ空を見る。
  - 昼夜: 1周 = 実時間24分（ゲーム内1時間 = 実1分）。経済の「1日=60秒」(src/economy/market.ts DAY_SECONDS) とは別の見た目用の時計。
  - 季節: 実時間6時間ごとに 春→夏→秋→冬（1年 = 実1日）。
  - 天気: 実時間10分ごとの枠をハッシュして 晴れ/くもり/雨/雪（雪は冬だけ、冬の雨は雪に）。
- 見た目 `src/world/Climate.tsx`: Scene.tsx の Sky・太陽・半球光・霧を時刻と天気で動かす。夜は街灯（Streetscape の MAT.lamp）と窓ガラス（materials.ts glassMaterial）を光らせる。雨・雪はカメラの周りに粒を降らせる。冬は地面を白っぽく。
- 相場: 天気・季節で相場に軽い係数（±3%程度）を `market.ts` の価格計算に掛ける（PR #67 マージ後の main に合わせる）。
- 画面: 上のバー（所持金の下）に「春 12:30 ☀ 晴れ」。

## 進捗
