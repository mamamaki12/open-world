## 方針

- 問題（2026-11-12 に #176 の版で、スマホ縦 390×844・320×568・横 844×390・PC 1280×800 で撮って確認）
  - セーブ（スマホ）：☰ のメニューで「セーブ」を押すと、セーブの小窓がメニューの上に重なって出る。小窓とメニューの幅が違うので、縦は下にメニューの端（「設定」「セーブ」の札）が、横は右に「かせぐ」「わたし」の切れた見出しと札がはみ出して見える。
  - タイトル画面（横向きのスマホ）：題字・名前の欄・「ひとりで遊ぶ」が縦に並ぶだけなので、「みんなのワールドで遊ぶ」が画面の外に出て、下にずらさないと見えない。
  - 地図（縦向きのスマホ）：開いたときに町全体を幅に合わせるので、町が真ん中に小さく出て上下が森になる。320×568 ではさらに小さく、家の名前が読めない。
- 直し方（データ・計算・保存の形は変えない）
  - セーブ：スマホでセーブを開いたら、メニューのほかの組を隠し、セーブの中身をメニューの中にそのまま出す（重ねない）。上の「‹ セーブ」を押すとメニューに戻る。PC は前から中に出ているので変えない。
  - タイトル画面：横向きのスマホ（高さ 500px 以下）だけ、左に題字、右に名前の欄と2つのボタン・設定を並べる（#174 の横向きの2列と同じ考え）。縦・PC は変えない。
  - 地図：縦長の画面（高さが幅の 1.2 倍より大きい）だけ、町全体の 2 倍の大きさで自分を真ん中にして開く（地図の外は出さない）。2 倍だと家の名前の札も出る。右上の ✕ の下に「町全体」ボタンを出し、押すと今までどおり町全体、もう一度押すと「自分のまわり」に戻る。PC・横向きは今までどおり町全体で、ボタンも出さない。
  - 縦向きのスマホで地図のお店を順に押す検査（check-official-shop-warp・check-gameplay-regressions）は、先に「町全体」を押すようにした。
- 使い方の改善と見た目の直しで新しい機能ではないので、version は変えない（docs/versioning.md の PATCH）。
- やめたもの：なし。
