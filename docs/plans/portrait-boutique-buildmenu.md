## 方針

- 問題（2026-11-12 に #175 の版で、スマホ縦 390×844・320×568・横 844×390・PC 1280×800 で撮って確認）
  - 服の店・クローゼット：商品の絵の上に、絵と同じ大きさの斜めの矢印（⤢）が重なる。「試着する ↗」の矢印のアイコンに、商品の絵のための「絵を枠いっぱいに広げる」指定が当たっていた（`.garment-image svg`）。PC・スマホとも。矢印に押されて「試着する」が左上の「着用中」と重なる。英字の札・件数・説明が 8〜9px で読めない。
  - 建築メニュー（スマホ縦・タブレット）：下から出るはずのシートが画面の上に貼り付き、高さ 90% のまま。道具を選ぶ前は下半分が空白で、シートの下にも灰色のすき間が出る。`.touch .overlay { align-items: stretch }` が `.touch .build-menu-overlay { align-items: flex-end }` より後ろにあって勝っていた（#117 から）。
  - 家具をデザイン（スマホ縦）：見出しが「家具を／デザイ／ン」と3行に折れる。320×568 では「引き出し・扉を開けてみる」が下の「ひな形から始める」のボタンに重なる。
  - 運転中（スマホ縦）：ペダルの下の「アクセル」が「アクセ／ル」と2行に折れる（#175 で文字を 12px にしたため）。
- 直し方（CSS が中心。データ・計算・保存の形は変えない）
  - 服の店：絵の指定を商品の絵だけ（`.garment-image > svg`）にし、矢印は文字の大きさに。「着用中」「試着する」は白い札にのせて左上・右下に分ける。8〜9px の文字は 11〜12px、薄い灰色は濃くする。札の英字（OWNED・COLLECTION）は「持っている」とし、まだ持っていない服には札を出さない。件数の「9 ITEMS」は「9点」。
  - 建築メニュー：`#root .touch .build-menu-overlay` で下に付ける（横向きのスマホは今までどおり画面全体）。道具を選ぶ前は中身の高さだけになり、上に家が見える。道具を選んだあとは今までどおり 90% の高さで、下に付く。
  - 家具をデザイン：幅 480px 以下は、1行目に見出しと「閉じる」、2行目に名前と値段。見本の高さは行の高さに合わせる（`min-height: 0`）。
  - 「アクセル」の札だけ左右に 6px 広げて1行にする（文字の大きさは 12px のまま）。
- 使い方の改善と見た目の直しで新しい機能ではないので、version は変えない（docs/versioning.md の PATCH）。
- やめたもの：なし。
