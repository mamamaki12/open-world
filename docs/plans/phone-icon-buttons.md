## 方針

- 部品：src/ui/AppIcon.tsx に `IconLabel`（アイコン＋文字）を足す。スマホ（`.touch` または幅640px以下）では文字を「見えないが読み上げられる」形で隠し、`short` があれば短い文字を出す。PC は今までどおり（前は文字だけのボタンは PC ではアイコンも出さない）。絵文字は使わず、既存の AppIcon の絵を使う。
- 対象：パネルの閉じる・タブ、建築メニューの見出し（道具をしまう・決定）、☰ メニューの項目、セーブ／ロード、版の確認、写真モード、カジノ・バイト・車屋・不動産屋・操作設定・道具パネルの移動用ボタン。
- 文字を残す：お金・購入・取り消しにくい操作（買う・売る・購入を確定する・更地にする・保存・読込・やめる（給料なし）・給料を受け取る など）、品物の名前、説明文、ドアなどの場面ごとの操作。
- 押せる範囲 44px・すき間 8px（touch-target-spacing）を守る。scripts/check-ui-spacing.mjs に「名前のないボタンが0」の判定を足す。
- 機能追加ではないので version は変えない。
