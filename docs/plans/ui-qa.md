## 方針
- 公開版と同じ最新 main をローカル（vite dev）で起動し、Playwright（DPR 1、1440x900 / 1280x720 / 1024x700、スマホ 390x844・844x390 ?touch=1）で一通り触る。
- 対象: 歩行・建築・運転・カジノ・車屋・カスタムショップ・服屋・不動産屋・地図・メニュー。
- 見つけた問題をここに一覧化し、小さいPRに分けて直す。スマホはすっきり、浮いた文字ラベルは増やさない。
- CI 緑でマージ。コンフリクトは main を取り込んで解消。

1. 右下の「ひとりでプレイ中」がスマホで「建てる」ボタンに重なり、全てのお店・地図の画面の上にも浮く → PR A
2. スマホのスティック上「2回タップでジャンプ」がジャンプするまで出っぱなし → PR A（6秒で消す）
3. 地図の区画名が枠からはみ出して隣と重なる（PC・スマホ）→ PR B
4. PCの歩きモードで「地図」ボタンと「🗺 マップ」ボタンが二重 → PR B
5. 日付が変わったときの通知（相場・維持費）がモーダルの見出しに重なる（軽微、未着手）
