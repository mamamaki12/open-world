# 車を実車っぽく（外装・内装）＋カタログUIの見直し

- リモートブランチ: `claude/project-thread-2h3rj1`
- 依頼（しんご 2026-10-16）: 車がブロックのおもちゃ感が強いので実車っぽく。内装にもこだわる。車のカタログ（AVENUE MOTORS の購入画面）が見にくいので修正。

## 方針
- `src/world/CarModel.tsx` の車体を「押し出しの板」から、断面を丸めたロフト形状（前後の絞り・タンブルホーム・ホイールアーチの切り欠き）に作り直す。
- 細部：ヘッド/テールランプの形、グリル、ドアの合わせ目、ドアミラー、ドアノブ、丸みのあるタイヤ（Lathe）。
- 内装：形のあるダッシュボード、メーター（速度で針が動く）、センターディスプレイ、ハンドル（ステアで回る）、バケット/ベンチシート、センターコンソール、ドア内張り、ルームミラー、ペダル。
- カスタム（ストライプ・ツートーン・ウィング・車高・キャンバー等）と `driverEye` / `carBelt` は互換を保つ。当たり判定は寸法（cars.ts）なので変えない。
- カタログ：`src/ui/DealerPanel.tsx` / `vehicles.css` のみ触る（共通UIは別スレッドが修正中なので触らない）。

## 進捗
- 済: 計画。車体を断面ロフト（`src/world/carShape.ts`）に作り直し（丸い前後・フェンダー・ホイールアーチ・タンブルホーム・窓に沿った柱・ドアの合わせ目・ミラー・ドアノブ・形のあるライト/グリル・丸いタイヤ）。内装（ダッシュ・メーター針・ナビ画面・回るハンドル・シート・コンソール・内張り・天井・ルームミラー）を `CarModel.tsx` の `Interior` に。`driverEye` は運転席を少し後ろ（フロントガラスの付け根+1m）へ。
