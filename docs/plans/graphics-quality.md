# 画質を選べるようにする（高・中・低）

- 状態：公開待ち
- 残作業：PRのマージ
- 確認根拠：`scripts/check-graphics-quality.mjs`（スマホ縦の ☰ で低→解像度0.75・影なし・30fps以下・再読み込み後も低、PC の操作設定で低→高に戻る）。参考：swiftshader で1フレームの描画時間 高 443ms／中 113ms／低 4.6ms（スマホ縦 390×844、DPR2）
- ブランチ：`claude/project-thread-1nujds`

## 目的
しんご（2026-11-08）「スマホでも画質の品質を選べるようにしたい。高中低みたいな感じで、低にすれば描画処理の負荷も下がるように」「もちろんPCでもね」。

## 方針
- `src/state/graphics.ts`：画質（high / medium / low）を zustand で持ち、localStorage `open-world:graphics` に保存。初期値は PC＝高、スマホ＝中（今までと同じ見た目）。
- 画質ごとの値（`graphicsSettings()`）を Scene などが読む。
  - 解像度（dpr）：高 [1,2]／中 [1,1.5]／低 0.75 固定
  - 影：高 2048／中 1024／低 なし
  - 映り込み（Environment）：高 256／中 128／低 64
  - 細かい建物を描く距離（buildingLod）：高＝PC、中＝今のスマホ、低＝もっと近く
  - 家具の照明の数：高 6／中 3／低 1
  - 雨・雪の粒：高 全部／中 半分／低 1/4
  - 低はフレームを 30fps までにする
- 選ぶ場所：スマホの ☰ メニュー（歩き・建築）と「操作設定」（PC・スマホ）に「画質 高 中 低」。
