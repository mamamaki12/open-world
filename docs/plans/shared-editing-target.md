## 方針

- 初回スナップショットでは本人所有・共同建築許可の土地を優先する。通常の更新は利用者が選んだ閲覧先を保持する。
- 自分の購入操作がサーバーで確定した時だけ、購入対象へ切り替える。座標原点が変わっても人と視点の町での位置を保つ。
- 所有者・共同建築者の権限は緩めない。2人がそれぞれ土地を購入し、手動switchLotなしで自分の床を追加、再入場後の選択、元の共同建築許可のテストも維持する。
- 表示には編集中の土地と実際の建築可否を示す。サーバーのルールを変えずEC2更新を不要にする。
