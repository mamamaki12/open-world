# Web版のバージョン表示と最新版確認

- ブランチ: `codex/app-version-status`（mamamaki12/open-world）
- 依頼: バージョンを表示し、最新版になっているか確認できるようにする。

## 方針
- ビルド時に識別子・ソース版・日時を生成し、アプリ表示と公開version.jsonを一致させる。
- 開始画面とゲーム内のセーブ画面にWeb版の現在のバージョン、最新版の確認結果、再確認/更新操作を表示する。
- 確認は軽量JSONのみ取得。Service Worker/HTTPキャッシュの旧情報を使わず、オフライン・失敗・公開情報が古い場合は「最新版」と断定しない。
- 更新には既存の保存付きreloadLatestを使い、セーブを保持する。共有サーバーの版とは区別する。
- 比較・取得処理の単体と、生成した本番版で最新版/更新あり/オフライン/保存保持をブラウザ検証する。
