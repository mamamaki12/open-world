# Web版のバージョン表示と最新版確認

- ブランチ: `codex/app-version-status`（mamamaki12/open-world）
- 依頼: バージョンを表示し、最新版になっているか確認できるようにする。

## 方針
- ビルド時に識別子・ソース版・日時を生成し、アプリ表示と公開version.jsonを一致させる。
- 開始画面とゲーム内のセーブ画面にWeb版の現在のバージョン、最新版の確認結果、再確認/更新操作を表示する。
- 確認は軽量JSONのみ取得。Service Worker/HTTPキャッシュの旧情報を使わず、オフライン・失敗・公開情報が古い場合は「最新版」と断定しない。
- 更新には既存の保存付きreloadLatestを使い、セーブを保持する。共有サーバーの版とは区別する。
- 比較・取得処理の単体と、生成した本番版で最新版/更新あり/オフライン/保存保持をブラウザ検証する。

## 進捗
- 済: 最新main 766a066、既存の更新処理・SW・Pages公開処理とdocs/plans/README.mdを確認。実装前に計画をcommit/push。
- 次: バージョン情報の生成、キャッシュを介さない確認、表示UIと検証を実装する。
- 済: ビルドの識別子・ソース版・日時を生成し、開始画面/セーブに表示。PCの歩行中もセーブを開けるようにした。
- 済: version.jsonをSW保存対象から外し、確認要求はSW/HTTPキャッシュを使わず取得。通信失敗・オフライン・古い公開情報を区別する。
- 済: 比較/取得の単体6件と型チェック成功。production build成功。
- 次: 本番用ビルドでPC/小型スマホの表示・最新版判定・オフライン・セーブ保持をブラウザ検証する。
- 済: 本番用生成物とSWを使い、PC 1280×800とスマホ320×568で検証成功。現在版一致、新しい版、古い公開情報、不正な応答、オフライン再読込、ゲーム内表示、更新後の名前・ユーザーID・家の保持を確認。
- 済: 通信切替で自動再確認し、ブラウザがオフラインなら通信を開始せず未確認扱いにする。開始画面とゲーム内の画像も確認。
- 次: PRの最終CIとPages公開、公開version.jsonの確認を行う。EC2更新不要（対象はWeb版）。
