# 服屋UIと滑らかな人物・立体的な服

- ブランチ: `feat/boutique-fashion-and-avatar`（mamamaki12/open-world）
- 依頼: しんご「実在ブランドのオンラインショップを参考にUI改善。人物の継ぎ目を滑らかにし、服が体を覆う形に」

## 方針
- [COS公式](https://www.cos.com/ja-jp/women/view-all)と[UNIQLO公式](https://www.uniqlo.com/jp/ja/women/bottoms)の商品一覧を参考に、余白・商品イラスト・カテゴリ・並び替え・試着購入操作を `BoutiquePanel.tsx` / `boutique.css` に実装。架空ブランドを維持する。
- `Avatar.tsx` のIKとRig APIを維持し、`TailoredLimb.tsx` / `avatarGeometry.ts` で肘・膝をまたぐ連続メッシュをスキニングする。輪郭はスプラインで丸め、衣服の厚み・ゆとり・襟・袖・裾を作る。
- 購入・所有・セーブの契約を維持。道路・運転・車カスタムの他作業は変更しない。
- 単体テスト・ビルドに加え、`scripts/check-fashion.mjs` をCIの操作チェックに加える。

- 済: main同期、マージ済みPRと作業中ブランチのplans、旧実装、公式ストアを確認。方針のみを先にpush。
