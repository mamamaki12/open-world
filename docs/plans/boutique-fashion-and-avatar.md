# 服屋UIと滑らかな人物・立体的な服

- ブランチ: `feat/boutique-fashion-and-avatar`
- 依頼: しんご「実在ブランドのオンラインショップを参考にUI改善。人物の継ぎ目を滑らかにし、服が体を覆う形に」

## 方針
- COS/UNIQLO公式を参考に、大きな服の商品ビジュアル・余白・カテゴリ・並び替え・明瞭な試着購入操作を BoutiquePanel.tsx / boutique.css に実装。架空ブランドを維持。
- Avatar.tsx のIKとRig APIを維持し、連続したスキニングの手足、滑らかな頭、ゆとりと厚みのある胴・袖・裾を実装。ゲーム/マネキンにも反映。
- 購入/所有/セーブを維持。道路・運転・車カスタム作業は変更しない。
- 型チェック・単体テスト・ビルド、PC/390px/320px/横画面、試着・購入・着替え・屈曲を検証。

## 進捗
- 済: main同期、マージ済みPRと作業中ブランチのplans、旧実装、公式ストアを確認。
- 済: 商品イラスト/カテゴリ/並び替え/試着購入UI、滑らかな頭と連続スキニングの手足、ゆとりある服・袖・裾を実装。型チェック、513テスト、ビルド成功。
- 次: ブラウザで画面・購入・姿勢を確認し、必要なら修正。
- 課題: なし。
