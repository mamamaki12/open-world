# ブレーキ長押しでバック

- ブランチ: `feat/moving-double-tap-jump`
- 依頼: ブレーキを押し続けたらバックできるようにする。

## 方針
- スマホのブレーキペダルを保持すると減速し、停止後0.35秒で後退へ移る。後退速度は車種の上限に制限。
- アクセル同時押しやサイドブレーキ同時押しでは自動後退しない。離す・キャンセル・メニューで保持時間をリセット。
- 前進から急に後退しないこと、上限速度・操作解除・アクセルへの切替を単体/ブラウザ検証。

## 進捗
- 済: ダブルタップジャンプ、左右ボタン強化、減速緩和、サイドブレーキ・ドリフトを実装・検証して保存。
- 次: 長押し後退と案内を実装して最終検証。
