## 方針

- 問題（2026-11-10 に #166 の版で撮影して確認）：6つのゲームとも、初めて開くと `src/ui/casino/Guide.tsx` の遊び方が開いた状態で台の上に出て、台と賭けるボタンが下に埋もれる。スマホ横向きは遊び方の表だけで画面が埋まる。ロビーも横向きは「今夜は、どこで遊ぶ？」の帯で埋まり、ゲームの札が見えない。
- 遊び方は初めてでも閉じておく。初めてのゲームでは「遊び方」のボタンを光らせて知らせる（押したら光は止める）。
- 開いた遊び方は、スマホ（`.touch`）では画面の下から出るシートにして台を押し下げない。見出しに「閉じる」（44px）を置き、背景を押しても閉じる。PC は今までどおりその場で開く。
- 横向きのスマホ（高さ500px以下）では、ロビーの歓迎の帯を隠し、ゲームの札を3列で並べる。
- 文言・配当の計算は変えない。
- 台が先に見えるようになったことで、幅320pxのスマホでルーレットの下の2段（1st 12〜・1-18〜）のマスが上下に重なることが分かった（指で押す端末はマスが44px以上なのに、段の高さが40pxだった）。`.touch .roulette-table` の下の2段を44pxにして直す。
