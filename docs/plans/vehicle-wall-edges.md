# 車の壁の辺・角の当たり判定

- ブランチ: `fix/vehicle-wall-edges`
- 依頼: 車が壁の辺に当たっても判定がないので修正。

## 方針
- 3つの円だけでは漏れる車体四隅と壁の端を、車体の向きに沿った矩形と壁線分の交差で補う。
- 車の障害物一覧にデフォルト住宅も含める。所有住宅・外構と同じ扱いにする。
- 高さ、開いたドア、離れた壁、後退・斜め進入・ドリフト、衝突後に離れる動作を検証。

## 進捗
- 済: main 37a4c1c と衝突処理を確認。車体四隅の隙間、および障害物一覧に町のデフォルト住宅が含まれない問題を特定。
- 次: 車体矩形の壁判定と住宅一覧を修正し回帰検証。
