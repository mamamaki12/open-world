# 車の壁の辺・角の当たり判定

- ブランチ: `fix/vehicle-wall-edges`
- PR: #63
- 依頼: 車が壁の辺に当たっても判定がないので修正。

## 方針
- `vehicleWalls.ts`: 車体全体の向き付き矩形と壁線分の交差で、従来の3つの円から漏れた四隅を保護。店舗の直方体には4軸の分離軸判定。
- `vehicleLogic.ts`: デフォルト住宅を車の障害物に含める。近隣の住宅だけを対象とし、一覧をサブステップ間で共有。開口は家ごとに索引を共有。
- 高さ、開いたドアの幅・高さ、後退・斜め進入・ドリフト、衝突後に離れる動作を検証。

## 進捗
- 済: main 37a4c1c を確認。車体四隅の隙間、およびデフォルト住宅が車の障害物に含まれない問題を修正。
- 済: ローカルの型チェック、全573テスト、本番ビルド成功。追加8テストで全10車種・各角度の四隅と壁端、店舗の直方体との交差を検証。
- 済: ヘッドレスChromeで実際のdriveFrameを使用し、車体四隅で停止・バックによる離脱・店舗の角で停止を確認。デフォルト住宅19区画の塀のblockedAtもすべて成功。
