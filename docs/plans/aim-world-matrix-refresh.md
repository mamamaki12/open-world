## 方針
- 照準判定前にカメラと対象root配下のworld matrixを更新し、描画フレーム間に追加された町の建物を実際の位置で判定する。
- `placementRay.ts`に中央rayの共通処理を置き、`AimBuilder.pick`から使用。新規meshの未更新行列とカメラ移動を単体検証する。
- スマホ照明の実タップ、PC照明、既存操作・描画・セッションCIを確認する。Webのみの修正でEC2の再更新は不要。
