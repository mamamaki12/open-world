# ユーザーが自分で考えたお店を開く（第1段階・実装方針と進捗）

- ブランチ: `claude/project-thread-lojfxx`（mamamaki12/open-world）
- 依頼: しんご「業種を選ぶのではなく、ユーザーが頭で考えたビジネスをできる仕組み」→ 第1段階「店舗指定＋レジ＋自由な商品登録＋一回払い」でOK（2026-10-16）
- PR: #72（base は #74 のブランチ `claude/project-thread-p9vaed`）

## 方針
- 業種は持たない。道具だけ渡す: 自分の土地を「お店」に指定 → レジ（家具）を置く → 商品・サービスを自由に登録（名前・写真＝その場のスクショ・値段・説明）→ 他のプレイヤーが一回払いで買う。
- データ: `Lot.shop?: Shop`（`src/state/economy.ts`）。ワールド保存に含まれるので訪問者にも見える。純粋ロジックは `src/economy/shop.ts`（検証・上限・購入記録）。共有ワールド化（`feat/shared-public-world`）でサーバーに移すときもそのまま再利用できるよう描画非依存にする。
- お金はユーザー間: 買い手の所持金 → 店の持ち主（いまはワールドのホスト）へ。運営からの売上は出さない。自分の店では買えない。
- 支払い: みんなのワールド（#74）のサーバー正本に乗せる。`src/server/sharedWorld.ts` の applyAction に `shop`（持ち主だけが開店・商品更新。売上記録は書き換え不可）と `purchase`（買い手の口座→持ち主の口座、recordSale）を追加。クライアントは `sessionGate.act`。ひとりで遊ぶときは店の準備だけでき、買えるのはみんなのワールド。旧招待ルームでの購入はなし。EC2 更新は #74 と1回にまとめる（このPRは #74 のブランチ向け）。
- 写真: WebGL画面を 320px JPEG に縮めて保存。1店 12商品まで、説明 200字まで。
- 店の売上記録（直近50件）は誰でも見られる（将来の信用・レビューの土台）。
- 後回し: 雇用・月額・権限貸し・レビュー。

## この先の順番（しんご 2026-10-16「全部追加で」）
各段階を小さなPRに分ける。プレイヤー間のお金（報酬・雇用など）は共有ワールド（`feat/shared-public-world`）の仕組みに乗せる。
1. 第1段階（このPR）: 店舗指定・レジ・自由な商品登録・一回払い
2. すぐ建つ店: プレハブ店舗・屋台・テントを空き地に数秒で設置（家具セットとしてまとめて置く）
3. 売り物の種類を広げる: 同じ登録画面で物・サービス・入場券・予約・会員権（期限つき）
4. 人を集める: 看板・チラシ・地図へのピン・イベント告知
5. 人を動かす: 雇う・仕事を頼む・報酬の約束（手付金を預かる仕組み）
6. お店に動き: ミニゲームや乗り物を置いて遊ばせて料金を取る
