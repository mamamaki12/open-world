# ユーザーが自分で考えたお店を開く（第1段階・実装方針と進捗）

- PR: （出したら書く）

## 方針
- 業種は持たない。道具だけ渡す: 自分の土地を「お店」に指定 → レジ（家具）を置く → 商品・サービスを自由に登録（名前・写真＝その場のスクショ・値段・説明）→ 他のプレイヤーが一回払いで買う。
- データ: `Lot.shop?: Shop`（`src/state/economy.ts`）。ワールド保存に含まれるので訪問者にも見える。純粋ロジックは `src/economy/shop.ts`（検証・上限・購入記録）。共有ワールド化（`feat/shared-public-world`）でサーバーに移すときもそのまま再利用できるよう描画非依存にする。
- お金はユーザー間: 買い手の所持金 → 店の持ち主（いまはワールドのホスト）へ。運営からの売上は出さない。自分の店では買えない。
- 支払い: 既存の共同建築の預かり金（`savedBundle().pending` / receipts / settle）と同じ仕組みに乗せる。客はお金を預けて `purchase` を送り、ホストが receipts に記録・保存してから結果を返す。届かなければ再接続時の settle で返金。relay に `purchase` 転送を1行追加（EC2の更新が必要。旧relayでは購入が届かず自動返金されるだけ）。
- 写真: WebGL画面を 320px JPEG に縮めて保存。1店 12商品まで、説明 200字まで。
- 店の売上記録（直近50件）は誰でも見られる（将来の信用・レビューの土台）。
- 後回し: 雇用・月額・権限貸し・レビュー。

## 進捗
- 済: 最新main確認、計画push。共有ワールドは計画のみで未実装（同ブランチのplans参照）。
- 次: `src/economy/shop.ts` とテスト → レジ家具 → 店の管理/購入パネル → session の purchase。
- 課題: オフラインでは客がいないので売れない（共有ワールド完成で解消）。
