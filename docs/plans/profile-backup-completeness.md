# バックアップの個人データ欠落

- ブランチ: `codex/fix-verified-gameplay-bugs`
- PR: #87（draft）
## 方針
- `src/session/saves.ts`の個人バックアップに見た目/作成済みフラグ、個人ワールドの保有株、家具デザインライブラリを保存する。
- 共有の保有株・車と個人ワールドを混同しない。旧version1バックアップは任意フィールドとして引き続き受け付け、欠落フィールドで既存の個人データを消さない。
- 別ブラウザーへのimportとreload、旧バックアップ、共有からの復帰を確認する。
## 進捗
- 済: バックアップを別ブラウザーへ復元すると、女性/ポニーテール→初期男性、保有株→ゼロ、家具ライブラリ→ゼロになることを再現。既存のプロフィールには対象フィールドがない。
- 済: 計画を先にpush。SaveBundleに任意フィールドを追加して旧version1と互換を保持。見た目・個人保有株・未配置デザインを復元する単体テスト成功。
- 次: 別ブラウザーのimport/reload・共有からの復帰と全体検証。
