## 方針

1. スマホで床・壁を選ぶと真上の視点になり、道具を替えると元のカメラに戻る（`src/world/BuildCamera.tsx` の preciseTouch）。戻すときは「元の角度・距離」だけ戻し、注目点（target）は真上の画面でずらした場所のままにする。
3. 道具を持った1本指が土地の外から始まると画面が回る（PR #163）。真上の視点（床・壁）では1本指で回さない（土地の外から始めた指は何もしない）。回すのは回転ボタンか2本指。
4. 真上の視点で「左に回る／右に回る」を押しても見た目が変わらない。真上でも target のまわりに回るようにする。壁は真上から細い線にしか見えないので、真上の視点のときは壁の上端を濃い色で太めに見せる。
5. PC 1280px で相場の ▲▼ が付くと上のバーが2段になる。▲▼ の場所を常に空けておき、狭い画面向けの詰めた表示に切り替える幅を広げる。
6. 屋根の範囲が赤くなっても理由が出ない。赤いプレビューの間、理由（canPlaceRoof・床の置けない理由）を窓と同じように画面に出す。
7. 斜めから範囲を狙いにくい。屋根は壁の上端の面で読む処理が既にあるので、プレビューに「何マス×何マス」を出し、PCでもドラッグ中の寸法表示（DragMeasure）を出す。
8. 新しく始めると見本の家が数に入り、ガイドが 4/5 から始まる。チュートリアルの開始時の床・壁・ドアの数を覚えておき、それより増えたら達成にする。
9. 遊んでいるうちに夜になって暗い。建築画面（歩きでない）では夜でも明るさの下限を上げる。
10. みんなのワールド：`src/session/session.ts` の submit は確定待ちの間は表示を変えず、次の建築も「前の変更を確定しています」で止める。建てたら手元の家にすぐ反映し、確定待ちの間の次の建築は列に並べて順に送る。サーバーから町が届いたら、未確定の変更を上に重ねて表示する。断られたら列を捨てて町の正本に戻し「建築を取り消しました：理由」と出す。中継サーバーは変えない。
