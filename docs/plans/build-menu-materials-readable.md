## 方針

- 対象：スマホの建築メニュー（src/ui/BuildMenu.tsx）と、その中の種類・素材・色（src/ui/ToolOptions.tsx・src/ui/FinishPicker.tsx・src/ui/thumbnails.ts、mobile.css の `.build-menu*`）。PC の左の道具パネルも同じ部品を使うので、悪くならないことを確かめる。
- 道具を選んだら、11枚の道具カードを上の1列（横にスクロール、アイコン＋名前、高さ44px以上、選んだものははっきり）にまとめ、残りの高さを種類・素材の1つのスクロールにする（入れ子のスクロールをなくす）。道具を選ぶ前は今のカードの並び。スマホ横は左の細い列に道具、右の全部の高さを設定に使う。
- 素材：「N種から選ぶ」を高さ44px以上の本物のボタンにし、開いた一覧は 56px 以上の見本＋名前＋値段。選んだものは太い枠とチェック。色の見本は 44px、虹色の「色を選ぶ」に文字を付ける。
- 家具：分類（家の中・照明・外構・庭・自分のデザイン）の切り替え札と見出し、前から見た小さな絵（thumbnails.ts で部品から描く）を付けて2〜3列に並べる。選んだものは太い枠とチェック。
- 文字：見出し・名前は13px以上、補足だけ12px。補足の色は紙の地に対して 4.5:1 以上。携帯ゲーム機の見た目（紙 #f5f0dc・墨 #29392f・緑 #3e634c）はそのまま。
- 機能・データ・動き（家具は選ぶとすぐ閉じる、表札は閉じない等）は変えない。修正なので version は変えない。
