# 画面の要素の重なりを徹底的になくす

状態: 完了（PR待ち）
ブランチ: `claude/project-thread-jqhtsq`
残作業: なし
確認根拠: check-ui-overlap-all（7サイズ×約45画面）がローカルで全部通過。CI の ui-overlap-all ジョブで毎回走る

## 目的
しんご 2026-11-10「要素が重なってしまうところがないか徹底的に確認して修正」。
PR #159 の `check-hud-overlap.mjs`（歩く・建築画面×道具）と `check-large-text.mjs`（文字拡大）では、
普通のスマホ・PCサイズのパネル（カジノ・お店・地図など）、運転中、カジノの各ゲーム、ドアなどの操作ボタンが見られていない。

## やり方
- 新スクリプト `scripts/check-ui-overlap-all.mjs`：スマホ縦横（390x844・844x390・320x568・568x320）、タブレット、PC（1280x720・1440x900）で
  - 全パネル（store の Overlay 全種類）とパネル内のタブ（カジノのゲームなど）
  - 運転中・助手席、歩く画面のメニュー、ドアの前（操作ボタン）
  を `layout-scan.mjs` で検査し、重なりを一覧にする。
- 見つかった重なりを CSS で直す。CI の large-text ジョブで新スクリプトも走らせる。

## 見つかった重なりと直し方
- スマホ縦：競輪・競馬・ボートの出走表の見出し（会場・レース名 × 距離・頭数）が折り返して重なる → 見出しを折り返せる横並びにした
- パネル（不動産屋・カジノ・バイト・証券取引所など）を開くと、後ろの上のバー・所持金・地図ボタン・歩きモードの説明がパネルの端に半分隠れて重なって見える（スマホ横のバイト、タブレットの証券取引所、PC全般）→ パネルを開いている間は後ろのボタン・文字を隠す（3D画面とお知らせはそのまま）
- スマホ縦の建築画面：左上のガイド「はじめての家づくり」が上の操作説明（タップ：選ぶ…）に重なる → 縦向きは操作説明を画面の下へ
- 幅320pxのスマホ：左上の ☰・所持金・↶・↷ が2行に折り返して ↷ が建物の上に出る → 360px以下は少し小さくして1行に
- 検査に「パネルの端に後ろの表示が半分隠れていないか」の判定を追加
