## 方針
- 仮の「チラシ配り」（`src/state/economy.ts` の `startJob`、`src/ui/EstatePanel.tsx` の `Ledger`）をバイト一覧に置き換える。
- 1回 = 1シフト（約30〜45秒）。正確さと速さで給料が決まる（基本給＋出来高、ミスは減額、最低保証あり）。
- バイト4種（実際の作業に近いもの）
  1. コンビニのレジ：商品をスキャン→合計→お客さんの出したお金からおつりを硬貨・お札で渡す
  2. 倉庫の仕分け：荷物の伝票（配送先の地域）を見て正しいカゴへ
  3. ハンバーガー屋：注文票どおりにバンズ・具を順番に積む
  4. 交通量調査：通る車を種類ごとにカウンターで数える
- 純ロジックは `src/economy/jobs.ts`（問題生成・採点・給料計算、vitest）、UI は `src/ui/jobs/`。給料は `useEconomy.receive` で家計簿に記録。
- 他スレッド担当の 初期資金・着工無料・土地代・証券 には触らない。
