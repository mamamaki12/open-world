# 町に最初から建っている家を増やす（実装方針と進捗）

- ブランチ: `claude/project-thread-11epff`（mamamaki12/open-world）
- 依頼: しんご「デフォルトで建っている家を増やす。マンション・アパート・一軒家など、実在の建物に寄せる。全てユーザーが使えるパーツで。積水ハウスなどを見習い内装も。必要なら家具・建材も追加」

## 方針
- 家のデータ: `src/building/townHouses.ts`（デザイン14種）、組み立て道具 `src/building/townHouseKit.ts`（壁・床・窓・階段・屋根・家具＝ユーザーと同じ部品のみ）
- 区画の割り当て: `TOWN_HOUSE_PLOTS`（`src/economy/town.ts`）。その区画は売り土地に出さない（`freePlot` と `placeOffers` で除外）。はじめの土地(0)は使わない。店（カジノ・車屋）まわりの区画 19〜22 は触らない
- 追加カタログ: 家具15種（洗面台・下駄箱・対面キッチン・食器棚・ローテーブル・座卓・洗濯機・クローゼット・カーテン・フロアライト・エアコン・L字ソファ・集合ポスト・庭木・生垣）、外壁2種（彫りの深いコンクリート外壁・陶版外壁）。値段は prices.json
- テスト: `src/building/townHouses.test.ts` が建築ルール（canPlaceWall/Floor/Opening/Roof/Stair）で1つずつ置き直して検証。3階以上（マンション等）はプレイヤーの上限（2階）を超えるので階段の判定だけ外す
- 描画（未着手）: `src/world/Town.tsx` の `neighbors` グループ内に、持ち主のいない区画（自分の土地・売り土地を除く）の家を描く。部品が多いので、一度オフスクリーンで HouseParts を描いてから素材ごとにジオメトリを結合した静的メッシュにする（1フレームに1軒ずつ）。クリックで編集されないようにする
- 衝突（未着手）: `src/world/Player.tsx` の `resolveTown` に町の家も加える（x と z の両方で近いものだけ）
- 地図（任意）: `src/ui/MapPanel.tsx` で建っている区画に家の名前を出す

## 進捗
- 済: カタログ追加、家14種のデータ、区画割り当てと売り土地からの除外、検証テスト
- 済: テスト全通過（外階段の横に階段室の壁を足して踊り場を支えた）
- 済: 描画（src/world/TownHouses.tsx、素材ごとの結合メッシュ・1フレーム1軒）、衝突（Player.tsx resolveTown）、地図に家の名前と説明
- 次: PR を出して CI 緑ならマージ
- 課題: 性能（タワーマンション9階など部品数が多い）。描画は必ず結合メッシュにすること

## 追加：ほかの人の家に入れるようにする（しんご 2026-10-16）
- 依頼: 他の人の家にも入れるように。家の削除や人の土地への建材の配置はできないように
- ブランチ: `claude/project-thread-11epff`（PR #51 マージ後に main から作り直し）
- 方針: `src/world/visit.ts` の `visitAt(x,z)` で、いる区画の町の家を求め、Player の床・天井・屋根・ドアの判定をその家（区画ぶんずらした座標）で行う。衝突は `resolveTown` で開いたドアを通れるようにした。訪ねている家だけ `TownHouses.tsx` で部品ごとに描いてドアが動く。建築モードで触ると「ほかの人の家なので変えられません」と出るだけ（`activate` に読み取り専用の関数）。歩きモードの照準は自分の土地しか狙えない（既存）。家具の配置は自分の土地の外なら拒否（PlacementController）
- 区画ごとに部品 ID を分けた（同じデザインの家でドアの開け閉めが連動しないように）
- 済: 実装・スクショ確認（1階LDK・2階・マンションのロビー）
- 次: PR → CI緑でマージ
- main で10階建てまで建てられるようになった（#53）ので、マンションの外階段を上下の階で重ならない直階段に変え、全デザインが建築ルールどおりになった
- 未対応: 訪ねた家の椅子に座る・窓を乗り越えるのは不可（自分の家だけ）
