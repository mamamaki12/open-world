# スマホの運転画面と相乗り

ブランチ: `claude/mobile-driving-ui-9c3qhy`（しんご 2026-10-17）

## 目的
- スマホの運転画面を見やすく：上の横長ボタン4つをやめる
- ライトは常にON（切替ボタン・Lキーを削除）
- 視点は丸アイコン1つ。タップごとに3人称⇔運転席視点
- 車の運転席ドア付近は「運転席に乗る」、それ以外の車まわりは「乗る」（助手席）
- 共有ワールドで他のプレイヤーの車に相乗りできる（中継サーバーは pose をそのまま転送するので変更不要）
- 不具合：しばらく運転していると納車場へワープ → サーバーの口座(account)が届くたびに古い車の位置で上書きしていた

## 方針
- `showAccount` は手元にある車の位置・向きを保つ。降車時に cars を新しい配列にしてサーバーへ位置を同期
- 乗車状態 `useVehicles.riding = {owner, car}`。owner=null は自分の車。pose に `riding` を載せ、相手側では乗っている人のアバターを隠す
- 乗っている間は毎フレーム車の助手席位置に追従、カメラは運転と同じ（3人称／座席視点）
