## 方針

- 同じ階で辺が正の長さで接する床をたどり、全高壁に支えられた床まで到達できれば設置を許可。延長回数の制限は設けない。
- 角だけの接触、隙間、別の階、支えのない循環、半高壁は支持としない。土地境界・重なりの禁止は維持する。
- 移動後の一括グループも完成後の接続関係で検証し、パーツ順に依存させない。
- 床の外側から同じ高さに配置を始められるかPC・タッチ操作で確認。エラー文と道具の説明を更新する。
- 支えを消した際の既存パーツの自動削除は今回追加しない。支えを失った床からの新たな延長は拒否する。
- 進捗はこのplanだけに記録し、plans/READMEは更新しない。
- 共有編集も同じrulesを中継にバンドルするためserver/dist/relay.mjsを再生成し、既存セーブ・設定を保持する更新スクリプトでEC2更新が必要。過去の確認でSSH鍵・AWS認証はなく、利用者のEC2 Instance Connect実行が必要。
