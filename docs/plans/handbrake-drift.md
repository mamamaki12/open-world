# 通常ブレーキの緩和とサイドブレーキ・ドリフト

- ブランチ: `feat/moving-double-tap-jump`
- 依頼: 通常ブレーキが強すぎるので弱め、サイドブレーキでドリフト可能にする。

## 方針
- 通常ブレーキの減速を穏やかにする。サイドブレーキはスマホの専用長押しボタンと運転中Shiftキー。
- 旋回中にサイドブレーキで車体の向きと移動方向をずらして横滑り。解放後はグリップを戻す。低速は停止用。
- 衝突、後退、メニュー・キャンセル時の入力解除、旧セーブ互換、スマホ幅と横画面を検証。
