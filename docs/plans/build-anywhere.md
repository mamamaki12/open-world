## 原因

- PR #130/#131 で他人の土地・町の家は編集可能になったが、編集先の切り替えは建築画面のクリック（src/world/Town.tsx の activate / editTown）だけ。
- 歩く画面の照準（src/world/AimBuilder.tsx の pick）は 'house'（いま開いている土地）と 'ground' しか編集対象にしないので、ほかの区画を狙うと置けない。

## 方針

1. src/state/editAnywhere.ts：いまの土地の座標の点から、どの区画か（いまの土地・ほかの土地・町の家・空き区画・売地・区画の外）を返す `editTargetAt`。
2. AimBuilder：ほかの区画を狙ってタップしたら、その土地を編集先に切り替え（activateOwnedHouse + originShift で人とカメラをずらす）、次のフレームでもう一度置く。町の家は claimTownHouse、空き区画は「みんなの土地」（town: true、持ち主なし、空の家）にしてから。何も当たらなければ地面（y=0）で区画を判定。
3. 売地は「買うと建てられます」、他人のお店・公式のお店・道路は置けない（理由を表示）。
4. 共有ワールド：relay の townHouse 操作を空き区画（売地でない・使われていない）にも広げる。RELAY_VERSION を上げ、server/dist/relay.mjs を再ビルド。
