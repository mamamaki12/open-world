# 視点・道具・建築操作

一人称の中央照準とホットバーで、歩きながら建てられます。三人称と上から見る建築モードも利用できます。

- 1〜9、ホイール、ホットバーのタップで道具を切り替えます。「種類・素材」で選択中の道具を設定します。PCはBでも開けます。
- 一人称では照準を合わせて配置します。PCは画面をクリックしてマウスを固定してから、左または右クリック。スマホは配置ボタンを押します。指一本のスワイプは見回しです。
- 床・壁・屋根は始点を決め、見回して終点に配置します。「範囲を取消」や道具切替、Escでキャンセルできます。始点を決めた階は変わりません。
- 届く距離は7m以内です。自分の土地だけが対象で、手前の建物や車を通り越して編集できません。対象パーツとプレビューで置く位置を確認できます。
- 削除は削除ツールで狙います。スマホでは400ms長押しで1パーツを削除し、短いタップでは消えません。取り消しで戻せます。
- 家具配置後は手ぶらに戻ります。壁付け表札は壁の手前側に固定し、入力した文字を使います。
- PCはWASDで移動、Ctrl・ShiftまたはWの2回押しで走り、Spaceでジャンプします。Spaceを押したままなら着地後もジャンプします。Qで視点、Fで開閉・着席などの近接アクション、Rで階段・家具を回します。
- スマホは左スティックで移動、端まで倒すと走る、スティックを2回タップするとジャンプします。
- 操作設定で感度、上下反転、照準建築の有効・無効を保存できます。三人称や照準建築を無効にした場合は従来の直接タップ・ドラッグ配置を使います。PCのShift＋ホイールは従来の三人称の距離変更です。

CIでは単体テストに加え、ブラウザーで390px・320pxの縦画面と844pxの横画面、PCでの操作を確認します。床・壁・ドア・表札・家具の照準配置、スワイプ、長押し削除、ポインタ固定、ホイール切替、ダッシュ、連続ジャンプ、設定の保存を対象にします。画像はActionsのcontrol-checks成果物に保存します。

乗車時は周囲を見やすい三人称に切り替わります。一人称への切替も可能です。運転中のスマホ操作は、左下の左右矢印と右下のアクセル・ブレーキの4ボタンです。ハンドルとペダルを同時に押せます。指を離す・キャンセル・メニュー表示・画面を離れる操作で入力を解除します。

手ぶら以外の道具を持つと、ホットバーに「取り消す」「やり直す」が表示されます。範囲の途中で履歴操作をすると始点も解除されます。上から見るスマホの建築画面でも、履歴ボタンを文字付きで表示します。
