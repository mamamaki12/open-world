# スマホ画面での操作確認（2026-10-16）

Chromeのタッチエミュレーションで、320×568、390×844、844×390の画面を使用。テスト用の独立した保存領域で実施し、普段のセーブデータは変更していない。遠い場所への準備移動は開発用ブリッジを使用し、画面のボタン・スティック・スワイプは実際にブラウザーへ入力した。

## 再現して修正した問題

| 問題 | 修正 |
| --- | --- |
| 車カタログが390pxの画面で582pxまで広がる | グリッドと3Dプレビューの最小幅を修正。再確認では表示幅・スクロール幅とも390px |
| 横向きの家具編集が高さ336pxになり、見積もりが閉じるボタンに重なる | パネルを右下に寄せ、本文を画面高の42%以下に。見積もりを省略表示 |
| 歩行・建築・運転の切替後にHUDの高さが0になる | 表示切替ごとに計測対象を更新。メニューの展開部分を計測から除外 |
| 納車位置で三人称カメラがディーラーの壁内に入る | 不透明な建物の手前にカメラを寄せ、真後ろが塞がれる場合は空いた側面へ移動 |
| 視点切替が絵文字のみで分かりにくい | 切替先を文字で表示し、正面リセットを追加 |
| 地図の東側・店舗が初期表示で切れる | 全体表示、拡大・縮小、現在地へのスクロールを追加 |
| 不動産の「買う」が縦に折れ、価格が小さい | 縦画面は土地ごとの2段表示に変更し、購入価格・残高の確認を追加 |
| ルーレットの個別取り消しが右クリック前提 | タップで外すモードと盤面の横スクロール案内を追加 |
| 壁の高さ選択に選択中の装飾がない | 共通の選択ボタンのスタイルを適用 |
| 小さなボタン、表札入力時の文字サイズ、屋根スライダーの微小なはみ出し | 主なボタンを44px以上にし、文字入力を16pxに。スライダーの余白を修正 |
| 操作説明と削除中の1本指スワイプの動作が違う | 単体削除・範囲削除の説明を分離 |
| 入力が途切れた際にスティック操作が残る可能性 | キャプチャ喪失・非表示・フォーカス喪失時に解除。ダイアログ中は歩行ボタンをアンマウント |

## 操作した範囲

- 縦横の切替、歩行・建築の切替、視点切替、正面リセット。
- 建築9ツールの種類・材料メニュー。320pxと844pxで幅を測定。
- 指での壁と床の範囲配置、家具配置、5cm移動、編集パネルの開閉、削除中のスワイプ、取り消し。
- L字階段の選択、表札の自由入力、セーブ・ロード。
- 店舗のドアを開け、スティックで歩いて入店。不動産の土地一覧・確認・購入・所有地・ワープ、売地看板の購入画面。
- ディーラーの展示車スペック、カタログ、購入、納車場所での乗降、スティックでの発進、ライト、車内・車外カメラ。
- ソファへの着席と起立。
- カジノのロビー、6種類のゲーム、スロット実行、ハイ＆ロー実行、ルーレットのベット・実行・払戻表示・タップによる個別取り消し。
- 競馬の券売機で単勝の番号・金額・セット・購入・発券。レース中の購入券と全画面、結果・払戻表示。
- 競輪・ボートレースの観戦、全画面、結果への移動。
- 地図の全体表示、拡大、現在地、所有地一覧。

ブラウザーの実行時エラーは確認中に発生していない。カメラの壁回避に2件の回帰テストを追加し、既存を含む480件が成功。

実機のiOS Safari、ソフトウェアキーボードやノッチの実際の描画、端末固有の性能はこの環境では検証していない。
