# ゲーム設計書（たたき台 v0.1）

> しんごさんと一緒に詰めていくための下書きです。「未決」と書いた項目は、これから一つずつ相談して決めます。

## 1. コンセプト

- **一言で**：自分だけのワールドで、稼いで、建てて、売って、また建てる「住宅づくり×経済」クリエイティブゲーム。
- **プラットフォーム**：Webブラウザ（PC優先、スマホ対応は後で検討）。
- **体験の核**：
  1. 手軽に家を設計できる気持ちよさ（数クリックで部屋ができる）
  2. お金を貯めて、もっと大きく良い家を建てる成長感
  3. 建てた家が高く売れたときの達成感
- **遊び方のループ**：稼ぐ → 建てる → 売る（または住む・飾る）→ もっと稼ぐ

## 2. 住宅設計

### 2.1 視点と操作（決定：3D）
3Dで設計・表示する。自由に視点を回して見られる。置き方は「基本はマス目に吸着、家具などは自由に微調整」に決定。

### 2.2 設計の単位（案）
- ワールドは**区画（土地）**に分かれ、土地を買ってその上に家を建てる。
- 家はマス目（グリッド）上に置くパーツで作る。
  - **構造**：床、壁、ドア、窓、屋根、階段
  - **設備**：キッチン、風呂、トイレ（あると「住める家」として価値が上がる）
  - **家具・装飾**：ベッド、ソファ、植木など（見た目と価値に効く）
- 手軽さのための工夫：
  - 「部屋ツール」：ドラッグで四角を描くと床と壁を一度に作る
  - テンプレート（ワンルーム、2LDKなど）から始めて改造できる
  - 取り消し / やり直し

### 2.3 建築の流れ（案）
1. 土地を買う
2. 設計モードで自由に配置（この段階ではお金はかからない＝試し放題）
3. 「着工」で見積額を支払い、家が完成する
   - 完成までは短い待ち時間（数十秒〜数分）。その間にバイトなどができる

## 3. お金の仕組み

### 3.1 収入
| 手段 | 特徴（案） |
|---|---|
| アルバイト | 確実に稼げる。短いミニゲーム（例：レジ打ち、配達）で、上手いほど報酬アップ。職種が増えていく。 |
| ギャンブル | 一発逆転。スロット、ルーレット、ハイ＆ローなどのカジノ系に加え、競馬・競輪・ボートレースなどの公営競技まで全種類を実装する。期待値はマイナス寄りにして、バイトの価値を守る。賭け金上限はなし。 |
| 家の売却 | 建てた家を売る。中盤以降の主な稼ぎ方になる想定。 |
| 家賃収入（任意） | 家を売らずに貸すと、少しずつ収入が入る。採用するかは未決。 |

### 3.2 支出
- 土地代（場所や広さで変わる）
- 建築費（パーツごとの単価の合計）
- 家具代
- 維持費・税金（採用するかは未決。お金が貯まりすぎるのを防ぐ）

### 3.3 家の売却価格（案）
`売却価格 = (建築費 × 品質係数) + 土地の価値 + ボーナス`

- **品質係数**：設備がそろっているか、部屋の数・広さ、家具の充実度などで決まる。
- **ボーナス**：テーマがそろっている（和風、モダンなど）、庭がある、など。
- 「建てるだけで必ず儲かる」にはせず、工夫した家ほど高く売れるようにする。

## 4. 進行とバランス（案）

- **序盤**：所持金が少ない。バイトで稼いで小さな家（ワンルーム）を建てる。
- **中盤**：売却で利益を出し、大きい土地・新しいパーツを解放。
- **終盤**：豪邸、こだわりの街並みづくり。
- 解放の仕組み候補：所持金・累計売上・「建築レベル」でパーツや土地が増える。
- ギャンブルに賭け金上限はない。全部溶かしてもバイトで立て直せる。
